## 적용 기준

- 프로젝트의 `mapFlowColors`에서 화면 바탕과 패널, 검색 필드, 활성 탭, 강조 버튼, 기록 배지와 GPS 색을 가져왔다. 다크 지도용 지형과 도로 색, 지역명 대비와 손잡이 색을 화면 토큰에 정의했다. [토큰](tokens.json) · [디자인 명세](DESIGN.md)
- 승인된 좌표와 터치 크기로 성수동·서울숲·한강, 기록 7·기록 3·기록 5, 시연용 위치점과 지도 조작부를 배치했다. 64×44px 기록 터치 영역 안에 높이 32px의 시각 배지를 두고 텍스트를 세로 중심에 배치했다. GPS 위치점에만 작은 외곽 원을 사용한다. 줌을 적용한 지도와 개별 기록·필터 상태는 별도 설계 범위다.
- GPS와 기록 작성 버튼은 48px, 검색은 358×48px, 출처 버튼은 44×44px, 패널 드래그 영역은 390×44px다. 하단 탭 네 개의 높이는 52px이며 지도 탭을 연두색 아이콘·레이블과 선택 배경으로 표시한다. 해당 디자인의 위아래 안전 영역은 54px, 34px다.
- 승인 대기 값은 지도 배경과 색, 컴포넌트 모양, 레이블 크기, 아이콘과 상태의 시각 방향이다. [문구](copy.json) · [컴포넌트](components.json) · [자산 출처](asset-sources.md)

## 실행 검증

Chromium의 390×844 1× 캡처를 생성해 직접 열었다. 위치점과 기록 배지가 구분되고, 지도 하단의 출처 영역과 GPS·기록 작성 버튼이 간격을 두고 보인다. 패널 손잡이, 검색 필드와 탭을 한눈에 식별할 수 있다.

| 검증 | 결과 |
|---|---|
| 13개 레이아웃 및 문구 검사 | 모두 통과. 12개 터치 영역 최소 44×44px, 겹침 없음, 14개 텍스트와 로고가 지정 영역에서 잘리지 않음. |
| 텍스트 대비 14개 | 4.5:1 기준 모두 통과. 성수동·서울숲 레이블의 최초 대비 3.71:1·4.07:1을 높였으며 최종 최솟값은 성수동 5.01:1이다. 검색 6.43:1, 기록 버튼 10.86:1, 비활성 탭 10.33:1이다. |
| 아이콘·손잡이 대비 7개 | 3:1 기준 모두 통과. 손잡이 6.46:1, GPS 아이콘 9.07:1이다. |
| 실제 글꼴 | Chromium 플랫폼 글꼴 응답에서 14개 텍스트에 모두 Pretendard Medium 또는 Bold가 사용됐다. |
| 지도와 출처 로고 | 지도는 전면을 채운다. 로고는 88×23px 원본의 렌더 픽셀을 확인했고 다른 조작부와 겹치지 않는다. |

## 재현

저장소 루트에서 `node work/bugmap-main-map-harness/05-design-system/build.mjs`로 대표 SVG와 지도 자산을 만든다. 이어서 `node work/bugmap-main-map-harness/05-design-system/render.mjs`로 실제 Chromium에서 캡처와 검증 보고서를 생성한다. 생성된 디자인 명세는 하네스 `design-md`로 검사한다.

현재 검증은 대표 화면의 시각과 레이아웃에 해당한다. 실제 지도 SDK, 확대·묶음 해제, 드래그, 검색, 탭 이동, 위치 권한, 스크린 리더와 기기별 안전 영역은 구현과 기기 검증 범위다. 편집 가능한 Figma 노드는 디자인 시스템 승인 후 제작한다.
