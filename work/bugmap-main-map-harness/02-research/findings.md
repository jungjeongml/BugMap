# 레퍼런스 관찰

## Kyro 메인 화면

- **직접 본 것** — 도로와 다색 영역이 화면 가장자리까지 이어진다. 지도 위에는 개수·거리 배지가 다수 보인다. 패널 바로 위 같은 높이에 왼쪽 조준점 버튼과 오른쪽 ‘코스 만들기’ 버튼을 둔다. 둥근 하단 패널은 화면 높이의 약 4분의 1을 차지하며 손잡이, 돋보기와 ‘지도 영역’ 입력, 거리 칩, 아이콘·라벨이 있는 탭 순으로 읽힌다. 지도 탭은 노란 아이콘·라벨과 별도 바탕으로 강조된다.
- **가져올 점** — 지도를 넓게 유지하고 패널 안에는 검색·화면 전환, 패널 바로 위에는 위치 확인·기록 시작을 배치한다. 중심 손잡이는 위로 끌 수 있는 시각 단서로 활용한다. HOME-02~06에 적용한다.
- **피할 점** — 색이 강한 다수의 영역과 촘촘한 배지를 그대로 두면 곤충 기록과 현재 위치를 구분하기 어려울 수 있다. 승인된 다크 팔레트와 제한된 수의 모의 마커로 정보 위계를 잡는다. 거리 칩이 차지한 높이는 이번 접힌 상태에서 검색과 네 탭을 여유 있게 배치하는 데 사용한다. HOME-02~04·07.
- **해석과 미검증** — 조준점은 위치 기능으로 보이는 아이콘이다. 탭하거나 드래그하지 않아 GPS 기능, 실제 시트 확장과 이동 목적지, 탭 전환과 검색 범위를 확인하지 못했다.

## BugMap 02 메인 발견 지도

- **직접 본 것** — 서울숲·성수동을 표시한 모식 지도 위에서 ‘관찰 7’, ‘채집 3’, ‘관찰 5’ 집계 배지와 원형의 현재 위치 표시가 모양으로 구분된다. 선택된 기록의 요약 카드가 별도로 보인다. 하단 패널 바로 위에서 위치 버튼과 ‘발견 기록하기’가 좌우로 분리된다. 패널의 손잡이, ‘곤충 이름이나 지역을 검색하세요’ 필드, 지도에서 발견된 기록 요약, 다섯 탭을 확인했다.
- **가져올 점** — 위치와 기록 버튼의 좌우 배치, 검색 대상이 두 가지임을 알리는 문구, 원형 위치점과 집계 배지의 형태 차이를 이어간다. HOME-03·05~07.
- **피할 점** — 이전 시안의 다섯 항목, 기록 요약 행과 선택 카드까지 기본 화면에 넣으면 승인된 네 탭과 접힌 상태의 범위를 벗어나고 지도 표시 면적을 줄인다. HOME-01·02·04·07.
- **해석과 미검증** — 02는 이전 라이트 시안이다. 현재 다크 시안 07의 실제 픽셀과 상호작용은 확보하지 못했다. 다크 팔레트, 반경을 걸지 않은 기본 상태, CTA 문구는 저장소의 현재 규격에 따르며, 정적 화면에서 GPS 권한·확장·검색·기록 저장을 검증하지 않았다.

## Mapbox 출처 안내

- **직접 본 것** — 문서 캡처의 정적 지도 예시에서 Mapbox 로고는 지도 안 왼쪽 아래에 있고, 출처 링크들은 오른쪽 아래에 모여 있다. [1280×1000 캡처](captures/mapbox-attribution.png)
- **문서 내용** — Mapbox 지도를 쓰는 경우 로고와 출처 표시가 필요하다. 로고는 원형을 유지하고, 모바일 SDK는 출처를 여는 정보 버튼을 기본 제공한다. [공식 가이드](https://docs.mapbox.com/help/dive-deeper/attribution/)
- **가져올 점** — 지도 가장자리에 Mapbox 로고와 출처 버튼 전용 공간을 잡는다. 패널 경계와 GPS·기록 버튼의 표시·터치 영역을 모두 고려한다. HOME-07.
- **피할 점** — 기본 위치를 기기 화면의 하단으로만 가정하면 오버레이가 로고나 버튼을 가릴 수 있다. 와이어프레임과 Figma 시안에서는 출처가 가려지지 않는지 확인한다. 실제 SDK 표시와 조작은 구현 단계에서 검증한다.
- **해석과 미검증** — 모바일 SDK 정보 버튼의 동작은 공식 문서 내용이다. 참고 이미지는 웹 문서의 정적 지도이며 iOS·Android SDK에서 버튼을 조작하지 않았다.
