# 메인 발견 지도 구조·와이어프레임 검수

검토할 화면은 로그인 후 보이는 390×844 `main-map/default` 한 장이다. 지도와 기록 데이터는 시연용이다. 구조 문서에서 검색, GPS, 패널 확장, 탭 전환과 기록 작성의 도착점과 지도 복귀를 연결했다. [기본 화면 PNG](captures/main-map/default.png) · [편집 가능한 SVG](main-map/default.svg) · [흐름](../03-structure/flows.mmd)

## 검토할 배치

| 위치 | 확인 내용 |
| --- | --- |
| 지도 | 배경은 390×844에 걸쳐 이어진다. 가까운 관찰·채집 기록을 합산한 ‘기록 7’, ‘기록 3’, ‘기록 5’ 배지와 ‘내 위치’ 점을 형태와 문구로 구분한다. 묶음 배지를 누르면 해당 위치로 확대하고, 관찰·채집 유형은 개별 기록 상세에서 확인한다. 주변 반경 경계는 기본 화면에서 숨긴다. |
| 지도 하단 | Mapbox 로고와 SDK 출처 버튼의 자리를 패널 위에 확보했다. 44×44 출처 버튼은 GPS·기록 버튼과 별도 행에 둔다. |
| 주요 조작 | 왼쪽의 GPS 48×48, 오른쪽의 ‘발견/채집 기록하기’ 184×48을 같은 높이에 둔다. GPS 버튼의 동작은 현재 위치로 지도 이동이며, 기록 버튼은 기존 작성 화면으로 연결된다. |
| 접힌 패널 | 패널 상단은 y=656이다. 중앙 손잡이의 위쪽 드래그 영역 390×44에서 ‘내 주변 발견’을 열고, 목록의 ‘지도 보기’로 복귀한다. |
| 검색과 탭 | 358×48 검색창에 돋보기와 ‘곤충 이름 또는 지역 검색’을 둔다. 지도·커뮤니티·채팅·마이 순서로 높이 52px의 탭을 배치하고 지도에만 선택 표시를 둔다. |
| 안전 영역 | 상단 54px와 하단 34px를 시안의 기준으로 잡았다. 하단 탭은 y=808까지이고 하단 안전 영역은 y=810부터다. 시간과 홈 인디케이터는 시스템 영역을 나타낸다. |

이전 BugMap 02의 지도 위 좌우 조작과 검색 위치를 참고했다. 이번 화면은 승인된 네 탭과 검색창을 사용하고 패널 높이를 188px로 잡았다. 기록이 밀집한 지도에서도 배지가 크게 보이지 않도록 총건수 배지 폭을 84px에서 64px로 줄였다. 배지의 중심과 높이 44px는 유지했다. GPS와 로고·출처의 표기는 저충실도 자리표시자다. 후속 디자인은 실제 아이콘과 공식 지도 로고를 확인한다. [리서치 적용 제안](../02-research/recommendations.md)

## 확인한 결과

- 하네스 `wireframe`이 입력 JSON에서 SVG와 PNG를 생성했다. 최종 390×844 PNG를 직접 열어 검색·기록 레이블 한 줄, 총건수 배지 3개의 한 줄 표기, 탭 순서와 지도 선택 표시, 손잡이와 검색 분리, 출처 표시와 지도 조작부 사이 간격을 확인했다.
- 블록 좌표를 대조한 결과 버튼과 입력 11개는 터치 영역이 최소 44×44px이며 서로 겹치지 않는다. 해당 요소들은 시안의 상·하 안전 영역을 벗어나지 않는다. 손잡이의 별도 드래그 영역과 탭의 좌우 순서도 확인했다.
- 화면 목록의 제작 범위 1개와 상태 목록의 `main-map/default`, 하네스 생성 프레임 1개가 일치했다. 정식 프로젝트의 PRD 및 리서치 통과를 먼저 확인했다. 생성 결과의 다이제스트는 [하네스 리포트](wireframes-report.json)에 있다.

| 요구사항 | 현재 증거와 이후 확인 |
| --- | --- |
| HOME-01 | 390×844 기본 프레임 SVG·PNG를 생성했다. Figma 노드와 레이어 확인은 제작 후 진행한다. |
| HOME-02 | 중앙의 손잡이를 확인했다. 위로 드래그하면 ‘내 주변 발견’을 연다는 동작은 흐름에 반영했다. |
| HOME-03 | 돋보기와 두 검색 대상을 담은 문구, 358×48 검색 영역을 확인했다. |
| HOME-04 | 탭 네 개의 순서·선택 표시·터치 영역을 확인했다. |
| HOME-05 | 패널 왼쪽 위 48×48 버튼을 확인했다. 현재 위치로 이동하는 연결은 흐름에 반영했다. |
| HOME-06 | 패널 오른쪽 위 184×48 기록 버튼과 한 줄 레이블을 확인했다. 기존 작성 화면 진입 및 저장·취소 뒤 복귀는 흐름에 반영했다. |
| HOME-07 | 시연용 위치점과 총건수 배지의 구분, 주변 반경 경계 생략, 출처 요소 배치와 간격을 확인했다. 배지의 접근성 이름은 ‘기록 N개’로 정의했다. 다크 팔레트, 실제 로고·SDK 동작 및 접근성은 후속 디자인·구현에서 확인한다. |
| HOME-08 | 이 프레임의 배치와 표기만 로컬 PNG로 검수했다. 기존 Figma 노드 `7:2`·`19:2` 비교와 실제 최종 시안의 대비·레이어 검수는 제작 후 진행한다. |

## 검토 범위

승인 요청 범위는 기본 지도 구성과 조작의 위치·정보 순서다. 확장 패널, 검색 결과, 다른 탭, 개별 기록 상세, 기록 작성, 권한 안내의 화면은 이후 범위다. 드래그·스크롤·탭·검색·권한·SDK 정보·기기 내 위치와 저장은 정적 캡처에서 조작 검증하지 않았다. 390×844 이외의 기기 크기 및 실제 시스템 안전 영역도 검증하지 않았다.
