# 구조·와이어프레임 독립 비평

**3·4단계 독립 비평 판정은 `ready`입니다.** 승인 범위인 390×844 `main-map/default` 한 장에서 구조·정보 순서·주요 동작을 막는 문제는 발견하지 않았습니다.

- **버전과 증거** — 정식 저장소의 `PRD.md`, `requirements.csv`, `recommendations.md`와 임시본의 `wireframes.json`, `default.png`, `review.md`의 SHA-256이 각각 제공된 값과 일치했습니다. 생성 보고서의 JSON·SVG·PNG 해시도 실물과 일치했습니다. [390×844 PNG](captures/main-map/default.png)를 직접 열었습니다. `wireframe` 종료 코드 `0`과 `inspectStage`의 `issues: []`는 조정자가 전달한 실행 결과입니다.
- **HOME-01~08 대조** — 화면·상태 목록과 SVG·PNG가 기본 화면 한 장으로 일치했습니다. 지도 위 공개 기록 배지와 현재 위치가 구분되고 반경 경계는 보이지 않습니다. 출처 자리와 GPS·기록 버튼이 겹치지 않으며, 검색 힌트와 기록 레이블은 한 줄로 읽힙니다. 탭은 지도·커뮤니티·채팅·마이 순서이고 지도에만 선택 표시가 있습니다. 버튼·입력 11개와 별도 390×44 드래그 영역은 최소 치수를 충족하며 서로 겹치거나 시안의 안전 영역을 침범하지 않습니다.
- **동작과 복귀** — 구조 문서에서 드래그 → ‘내 주변 발견’ → ‘지도 보기’, 검색 적용·취소, GPS 권한 거부·위치 확인 실패, 기록 저장·취소, 다른 탭 및 출처 안내에서의 지도 복귀를 확인했습니다. **경미한 발견**으로, 손잡이는 36×4px의 옅은 윤곽선이어서 실제 지도와 패널을 적용한 뒤에도 확장 단서가 읽히는지 확인할 필요가 있습니다.
- **미검증** — 실제 제스처·검색·위치·저장·출처 버튼 조작, 최종 다크 지도와 공식 자산의 대비, 기기 안전 영역, Figma 편집 가능 레이어와 기존 `7:2`·`19:2` 보존은 후속 검증 범위입니다. 정식 저장소 복사 후 상대 링크 확인이 남았습니다.

## 후속 검수

다크 패널에서 손잡이의 시인성을 대표 화면 캡처로 확인한다.

## 총 건수 배지 수정 검토

**판정 — `ready`**

- 정식본과 스테이징의 390×844 PNG를 직접 열고 구조·와이어프레임을 대조했다. 스테이징 JSON·PNG·검수 문서의 SHA-256은 전달값과 일치했다. 정식 CLI 상태는 `wireframes: awaiting_approval`이다.
- `기록 7`, `기록 3`, `기록 5`가 64×44px 배지에 한 줄로 들어간다. 기존 84px 배지의 중심을 유지했고, 세 배지 영역 밖에는 변경된 픽셀이 없다. 현재 위치점과 지명도 구분된다.
- **경미:** 세 레이블의 글자 중심이 배지 중심보다 3px 위에 있다. 잘림이나 겹침은 없으며 고충실도 시안에서 세로 정렬을 확인하면 된다.
- 묶음 탭 후 확대하고, 계속 겹치면 목록에서 개별 기록을 선택하며, 상세에서 관찰·채집 유형을 확인하는 흐름이 MAP-05·06과 맞는다. 와이어프레임 범위는 승인된 기본 화면 한 장이다.
- **미검증:** 시연용 건수의 실제 합산, 확대·겹침·선택 동작, 다크 지도 대비, 실제 Mapbox 출처와 접근성 동작.
