# 실제 Figma 시안 독립 비평

**판정 · `needs_revision`.** 390×844 기본 시안은 승인된 화면의 내용과 구조를 재현했다. 6단계 통과에는 Mapbox 로고 검사와 필수 산출물 정리가 남아 있다.

**검토 근거.** 승인 `b95f6ebe-352d-4004-9602-93da1a83250f`의 기록 파일을 재해시해 불일치 0건을 확인했다. [승인 PNG](../05-design-system/captures/390x844-default.png)의 SHA-256은 `5f19fd1a0a34f989728dc05ef6fe4f8fd7dc7b9bcf954700808347eba0ce22c3`, [Figma 41:81 PNG](captures/main-map-default.png)는 `3c391df201a8b53222204ba5594e87db41ca6ce24f2b103d50ae5cd54ede9b2c`다. 두 PNG를 직접 열었다. [노드 JSON](nodes.json)의 SHA-256은 `7c6297a6e2716a382b87160daa7f19c9881493ccde5b6fe7cb29a6929e445c86`다.

- **차단 · 하네스.** 읽기 전용 검사에서 410개 노드 중 공식 Mapbox SVG의 흑백 채움 10건이 UI 토큰 검사에 걸렸다. 공식 형태와 색을 유지하면서 승인된 로고임을 검사기가 확인할 수 있어야 한다. 검토 시점에는 최종 변경 기록과 Figma 검사 보고서를 스테이징 중이었다.
- **중요 · 서체 일치.** 승인 서체는 Pretendard 500/700이고 Figma는 Noto Sans KR 500/700이다. 검색과 CTA 등에서 글자 폭과 획 차이가 보이며 잘림·겹침은 관찰되지 않았다. 지도 레이블과 `내 위치`는 어두운 외곽선이 더 두드러진다. Pretendard를 적용하면 두 캡처를 다시 대조하고, 대체 서체를 계속 쓰는 경우 변경 근거를 기록한다.
- **유지할 점.** 전면 다크 지도, 유형이 섞인 공개 기록의 총건수 `기록 7·3·5`, 파란 위치점과 동심의 작은 반투명 원, 가려지지 않은 출처, 좌측 GPS와 우측 CTA, 중앙 손잡이·검색·네 탭의 순서와 지도 선택 상태가 확인된다. 64×32 배지는 64×44 영역의 중앙에 있고 기록·출처·GPS·CTA·검색·탭·손잡이 영역 모두 최소 44px를 충족한다. 기존 `7:2`와 `19:2`는 최초 추가 및 벡터 보정 전후의 트리·PNG 해시가 각각 일치한다. [보존 기록](preservation.json)

**미검증.** 별도 Chromium 보고서는 이슈 0건, 승인 PNG와 변경 픽셀 0개이며 입력·출력 해시가 일치한다. Figma 실시간 재조회, 다른 프레임 크기에서의 배치, 드래그·검색·GPS 등 실제 조작은 이번 정적 검수 범위 밖이다.

## 반영

[Figma 변경 기록](change-log.md)에 실제 대체 글꼴과 벡터 보정 근거를 남겼다. [Figma 검사 보고서](../07-validation/figma-lint.json)에 실제 색상 검사 이슈를 보존했다.
