# 결정 기록

| 상태 | 결정 | 근거 |
| --- | --- | --- |
| 사용자 요청 | 로그인 직후 기본 지도, 곤충·지역 검색, 지도·커뮤니티·채팅·마이, GPS 단축 버튼, 발견 기록 버튼을 디자인한다. | 2026-11-19 요청. 메시지의 ‘체팅’은 기존 명세의 표기 ‘채팅’을 적용한다. |
| 사용자 요청 | 하단 패널은 위로 드래그해 확장한다. 이번 시안의 화면 상태는 접힌 기본 상태 한 장이다. | 확장 화면은 이후 디자인한다는 요청. |
| 작업 제안 | 검색 힌트는 ‘곤충 이름 또는 지역 검색’. | 검색 대상 두 가지를 바로 보여 주는 시안용 카피다. |
| 기존 명세 적용 | 드래그하면 ‘내 주변 발견’이 열리는 흐름을 명시한다. 버튼 레이블은 ‘발견/채집 기록하기’를 적용한다. | 메인 지도 화면 명세. |
| 작업 제안 | 390×844, 다크 지도와 BugMap 녹색 계열, 기존 로그인 프레임 오른쪽에 새 프레임 추가. | 기존 화면 명세와 대상 파일을 대조했다. |
| 참고 자료 | Kyro에서 지도 중심 배치, 지도 위 단축 조작, 하단 패널 구성을 참고한다. BugMap의 토큰과 Lucide 아이콘을 적용한다. | 첨부 `example/kyroMain.png`와 [기존 화면 명세](../../../docs/screens/main-map.md). |
