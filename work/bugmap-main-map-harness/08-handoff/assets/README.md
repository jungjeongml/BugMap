# 전달 자산

6개 파일의 바이트는 승인된 시스템 자산과 일치한다. 파일별 원본·버전·라이선스는 승인 자료에 연결했다. [출처와 사용 범위](../../05-design-system/asset-sources.md) · [승인 자산 해시](../../05-design-system/assets-manifest.json)

| 파일 | 사용 범위와 원본 |
| --- | --- |
| [map-dark.svg](map-dark.svg) | 승인 시안 및 테스트용 모식도. 지면·도로·공원·수면은 저장소 원본 벡터에서 가져왔다. 실제 앱 지도는 Mapbox SDK로 렌더링한다. |
| [mapbox-logo.svg](mapbox-logo.svg) | 정적 시안에 사용한 공식 Mapbox GL JS SVG. 원본 색상과 비율을 유지한다. 실제 앱은 SDK 기본 로고와 출처 버튼을 사용한다. [공식 원본](https://raw.githubusercontent.com/mapbox/mapbox-gl-js/main/src/css/svg/mapboxgl-ctrl-logo.svg) · [출처 안내](https://docs.mapbox.com/help/dive-deeper/attribution/) |
| [Pretendard-Medium.woff2](Pretendard-Medium.woff2), [Pretendard-Bold.woff2](Pretendard-Bold.woff2), [pretendard-OFL.txt](pretendard-OFL.txt) | 승인 미리보기의 Pretendard 1.3.9 Medium·Bold 웹폰트와 SIL OFL. |
| [lucide-ISC.txt](lucide-ISC.txt) | 사용한 Lucide 1.70.0의 라이선스. 앱 아이콘은 [매핑표](../../05-design-system/icons.csv)의 Lucide 컴포넌트를 사용한다. |
