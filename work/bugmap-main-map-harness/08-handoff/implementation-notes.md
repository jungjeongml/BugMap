| --- | --- | --- |
| HOME-01 | `41:81` 기본 화면, `41:798` MapCanvas, SystemArea | 지도는 화면 끝까지 채운다. 시스템 상태 표시와 홈 인디케이터는 기기가 담당하며 앱은 안전 영역 인셋을 읽는다. |
| HOME-02 | `41:449` MapSheet, `41:451` 손잡이 | 기준 패널 높이 188px, 상단 모서리 32px, 손잡이 36×4px. 위로 드래그해 ‘내 주변 발견’을 열고 ‘지도 보기’로 접힌 상태에 복귀한다. 확장 화면 시안은 별도다. |
| HOME-03 | `41:454` Search | 기준 358×48px, 문구 ‘곤충 이름 또는 지역 검색’. 결과 선택으로 검색 조건을 지도에 적용하고 취소하면 돌아온다. |

### 화면 구현과 검수

- [다크 색·글자 크기·치수](../05-design-system/tokens.json), [컴포넌트 계약](../05-design-system/components.json), [문구와 접근성 레이블](../05-design-system/copy.json), [Lucide 아이콘 매핑](../05-design-system/icons.csv)을 사용한다. 기기 크기에 맞춰 가변 폭과 인셋을 적용하고 모든 조작 대상에 최소 44×44 영역을 유지한다. 시스템 글자 크기 확대와 화면 읽기 순서를 실기기에서 확인한다.
- 지도에는 공개 가능한 좌표만 사용한다. Mapbox 레이어 기반의 클러스터·개별 마커와 공개 위치 처리, 조회 경합은 [지도 TDD](../../../docs/TDD.md#지도-표시와-내-주변-반경) 및 [제품 PRD](../../../docs/PRD.md)를 따른다. 지도와 위치점 및 건수는 시안에서 시연 값이다.
- 지도 SDK의 기본 Mapbox 로고와 출처 버튼을 사용한다. 패널과 카드가 열리는 상태에서도 로고가 보이고 출처 정보를 열 수 있는지 확인한다. 승인 시안에 쓰인 공식 로고의 검정·흰색, 종횡비, 투명도는 원본에 따른다. [자산 안내](assets/README.md)
- [화면 흐름](../03-structure/flows.mmd)과 [상태 정의](../03-structure/states.csv)가 동작 기준이다. Figma에 실제 검색·GPS·드래그·기록 이동은 연결하지 않았다.
- 대응 Chromium 화면과 원격 Figma 노드는 별도로 검수했다. Figma 410개 노드·Mapbox 채움과 윤곽선 12개는 이슈 0건이다. 웹 검사 이슈는 0건이며 승인 시안 대비 시각 임계 초과 픽셀도 0개다. [Figma 검사](../07-validation/figma-lint.json) · [웹 검사](../07-validation/web-lint.json) · [요구사항 대조](../07-validation/coverage.csv)
