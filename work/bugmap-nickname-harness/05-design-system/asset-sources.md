# 닉네임 시안 자산

- `assets/bugmap-logo-vector-lime.svg`는 [기존 BugMap 첫 로그인 디자인 시스템 원본](../../bugmap-login-map-harness/05-design-system/assets/bugmap-logo-vector-lime.svg)을 바이트 그대로 재사용했다.
- `assets/Pretendard-Medium.woff2`, `assets/Pretendard-Bold.woff2`, `assets/pretendard-OFL.txt`는 [기존 BugMap 발견 지도 디자인 시스템](../../bugmap-main-map-harness/05-design-system/assets/)과 동일하다.
- 지도 윤곽은 `render.mjs`의 독립적인 지형선 일러스트다. 실제 지도 데이터·사진·외부 배경을 사용하지 않는다. 대표 표식의 Bug 아이콘은 Lucide의 선 경로를 사용한다. [Lucide 아이콘](https://lucide.dev/icons/bug) · [라이선스](assets/lucide-ISC.txt)
- 시스템 시간·배터리·신호 및 한글 키보드는 앱 화면 내 배치 확인용 정적 모형이다. 앱의 시스템 UI 기능이나 실제 키보드 높이를 표현하는 검증 자료와는 범위가 다르다.
