# BugMap 닉네임 설정 디자인 하네스

신규 가입에서 발견 지도로 이동하기 전에 한 번 거치는 한국어 모바일 닉네임 설정 흐름이다. 현재 단계는 요구사항 검토다.

- [요구사항 초안](01-prd/PRD.md)과 [수용 기준](01-prd/requirements.csv)
- [Figma 대상과 기존 프레임](control/figma.json)
- [확정 사항과 설계 제안](control/decisions.md)
- [재개 기록](control/flow.md)

기준 문서와 첨부 참조의 버전은 [프로젝트 설정](control/project.json)에 기록했다. 단계 진행은 저장소 루트에서 `node tools/design-harness/bin/design-harness check --project bugmap-nickname-harness`로 확인한다.
