# 닉네임 설정 PRD 독립 검토

## 1차 비평

독립 PRD 판정 needs_revision. 해시 두 건 일치, Kyro·로그인·지도 PNG 직접 열었고 CLI check의 PRD 이슈는 사람 승인뿐. 중요 1: NICK-01 수용 기준은 신규 가입/저장 완료 계정만 검사해서 본문이 요구하는 ‘닉네임 미저장 재진입 → 설정’이 누락됨. 가입자 이름과 명시적으로 저장한 BugMap 닉네임을 구분하고 이탈/재실행 시 미설정 계정의 지도 진입 차단 및 완료 계정의 온보딩 생략을 수용 기준에 명시 권고. 중요 2: 2~12자를 가정하지만 NICK-04는 1자만 검증하고 상한/공백 단독·IME 완료 대전이가 비어 있음. 0/1/2/12/13자와 공백, 한국어 조합 완료 후 유효/무효 키보드 완료 및 오류 해제는 상태 명세 검수 항목으로 보강. 경미: PRD ‘세 상태를 시연’ vs CSV가 클릭으로 명시하는 것은 ready→지도뿐. 독립 프레임인지 세 상태 간 더미 전환인지 명시하고, 추가 프레임/기존 로그인 변경은 범위에 넣을 필요 없음.
