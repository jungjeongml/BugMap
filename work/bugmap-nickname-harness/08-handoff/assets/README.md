# 닉네임 설정에 쓰는 자산

- 브랜드에는 승인된 [BugMap 연두색 SVG](../../05-design-system/assets/bugmap-logo-vector-lime.svg)를 사용한다. 앱의 [기존 BugMap 워드마크](../../../../src/features/auth/assets/bugmap-wordmark.png)와 용도에 맞춰 대조한다.
- 지형선·관찰 표식의 벡터와 배치는 편집 가능한 Figma 화면, [승인 미리보기 소스](../../05-design-system/previews/nickname-setup--initial.html)와 [좌표 원본](../../05-design-system/layout.json)에서 확인한다.
- 관찰 표식은 프로젝트에서 사용하는 [Lucide Bug](https://lucide.dev/icons/bug)를 사용한다. [아이콘 목록](../../05-design-system/icons.csv) · [Lucide 라이선스](../../05-design-system/assets/lucide-ISC.txt)
- 서체는 [Pretendard Medium](../../05-design-system/assets/Pretendard-Medium.woff2)과 [Bold](../../05-design-system/assets/Pretendard-Bold.woff2), [라이선스](../../05-design-system/assets/pretendard-OFL.txt)를 참조한다. WOFF2는 승인 웹 시안의 서체 증거다. 앱 구현 때 플랫폼에 맞는 Pretendard 자산을 확보해 등록하고 실기기에서 확인한다.
- 운영체제 키보드와 상태 바는 네이티브 UI를 사용한다. [승인 정적 예시](../../05-design-system/captures/390x844-initial.png)
