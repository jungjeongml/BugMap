# Cursor MCP 닉네임 제작 도구

- `prepare.mjs`는 하네스가 기록한 시각 시안 승인과 입력 아티팩트 해시를 확인한다. 계획 JSON과 임시 Cursor 파일, 기존 파일의 백업을 별도 작업 디렉터리에 만든다. 임시 작업 채널은 Figma 앱에서 문서명, 페이지와 두 기준 노드가 일치할 때만 열린다.
- `adapter.mjs install`은 기존에 등록된 플러그인의 두 파일을 백업 바이트와 대조한 뒤 임시 명령을 반영한다. `adapter.mjs restore`는 같은 두 파일을 원본으로 되돌리고 SHA-256을 기록한다.
- `bridge.mjs`는 현재 채널의 `status`와 `baseline`으로 대상 확인 및 원본 대조를 먼저 실행한다. `build`는 파일 이름과 페이지, 승인 해시와 앵커를 일치시킨 경우에만 실행한다. `export`는 제작과 다른 호출에서 실제 노드·프로토타입·네이티브 PNG를 읽는다.
- `plugin.js`는 닉네임 상태 세 개와 로컬 공통 컴포넌트를 만든다. 대상 외 문서는 어떤 객체도 변경하기 전에 거절한다. 시작하기는 저장 가능 상태에서만 지도 41:81로 연결된다. 기존 Figma 출발점·원본 프레임을 보존한다.
- `evidence.mjs`는 원본·제작·재조회·복원 응답에서 대상, 매핑, 좌표, 문구, 프로토타입 연결, 보존 증거를 대조해 보고서를 생성한다. `prepare-web.mjs`는 승인된 웹 시안 원본을 복사한다.
