# 05 첫 로그인 Figma 제작 기록

2026-11-19에 승인된 디자인 시스템 `ae7e9258-e0ef-465b-a759-45c6bef54c98` 기준으로 Figma 데스크톱의 BugMapHaness Page 1에 `05 · 첫 로그인 / 지도 배경` 390×844 프레임 한 장을 만들었다. Node.js CLI에서 로컬 TalkToFigma 포트 3055, 채널 `o5pf3rim`을 사용했다. [대상 프레임 19:2](https://www.figma.com/design/Dan8qlRM20XPkk7Mtd5riw/BugMapHaness?node-id=19-2) · [CLI](cli/README.md)

- 제작 전 채널에서 기존 `02 · 메인 / 발견 지도` 프레임 `7:2`를 확인했다. 기존 지도 노드의 PRD 시점, 제작 직전, 최종 조회 본문을 비교했으며 SHA-256이 일치한다. 대상 페이지의 루트는 기존 지도와 이번 로그인 프레임 두 개다. 원본 BugMap에는 쓰기 명령을 보내지 않았다. 후속 채널에서 원본 05의 제작 전후 노드 정보, 레이어 목록 102개와 PNG가 일치했다. 원시 트리 명령은 해당 채널에서 지원되지 않았다. [기존 노드 보존 검증](preservation.json)
- 전체 지도·상하 페이드를 등록 PNG로, 로고를 배경 없는 `#C5EE79` 벡터 13개로 유지했다. 제목 두 줄과 부제는 두 수준의 세로 오토레이아웃으로 묶었으며 수정 전후 최종 캡처는 픽셀까지 동일하다. 본문·지도 레이블·약관은 네이티브 텍스트이고 관찰 경계와 Lucide Bug는 벡터다. 소셜 로그인 묶음은 세로 오토레이아웃이며 버튼 세 개가 각각 358×48px, 간격 12px, 모서리 속성 32px이다.
- 첫 캡처는 이미지 채우기가 로드되기 전에 생성됐다. 재내보내기에서 지도와 네이버·Apple 자산을 확인했다. 카카오 SVG 외곽 높이가 글자를 자르는 문제를 발견해 해당 프레임의 바깥 치수를 맞췄다. SVG의 비례 제약이 내부 벡터까지 바꿔, 원래 내부 좌표와 치수를 대조해 복원했다. 최종 PNG에서 세 제공자 문구 및 표식과 로고·지도 사례를 모두 확인했다.
- Figma는 기준 시안과 같은 Apple SD Gothic Neo 계열을 쓰지만 SVG 검토본의 고정 텍스트 폭과 Figma 네이티브 텍스트 폭에는 작은 차이가 있다. 두 줄 제목, 지도 구도와 버튼 순서, 안전 영역의 시각 배치는 유지했다.
- 원격 플러그인이 파일 키를 제공하지 않아 `remoteFileKey`가 null이다. 승인된 사용자 파일 링크에 문서명, 페이지 ID, 기존 지도 노드 대조를 결합해 대상을 확인했다. [원격 확인](remote-verification.json)
