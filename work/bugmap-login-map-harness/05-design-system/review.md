## 시각 비교

공통 다크 팔레트의 배경·텍스트·강조색과 Lucide 아이콘 규칙을 재사용했다. 이 단계의 390×844 배치와 제공자 구성, 지도 관찰 삽화는 05 로그인 기준이다.

- 원본 PNG, 원격 원본 로고의 투명 PNG, 최종 Chromium 캡처를 직접 열었다. 지도는 화면 끝까지 이어지고 로고 위와 버튼 아래에서 어두워진다. 원본 지도와 페이드를 합성한 배경은 원본 화면의 대응 지점 6곳에서 채널별 차이가 최대 2였다. [배경 비교](background-comparison.json)
- 무배경 로고는 x132, y72의 128×39.68 SVG 뷰포트를 사용한다. 실제 경로 외곽은 약 126.85×38.35이며 뷰포트 안에 있다. 원격 투명 PNG와 비교한 문자·곤충·핀 형태와 연두색이 대응한다. 로컬 벡터 원본과 비교해 색상 두 곳의 치환만 확인했다. [자산 검증](asset-verification.json)
- 제목 두 줄과 부제, 지도 사례, 세 로그인 선택지, 약관의 읽기 순서가 원본과 일치한다. 서울숲 관찰 경계는 원본 내보내기를 기준으로 그린 편집 가능한 근사 경로이며, 중앙 표식에 프로젝트의 Lucide Bug를 적용했다. 지명·관찰 텍스트와 카드 주변의 잘림·겹침은 보이지 않았다. 브라우저에서 지정한 한국어 서체 폴백은 Apple SD Gothic Neo로 확인했다. 원본 Figma의 텍스트 스타일은 Inter이며, 미리보기의 글자 모양에는 플랫폼 서체 차이가 있다. [아이콘 명세](icons.csv) · [렌더 보고서](render-report.json)
- 카카오·네이버·Apple은 x16, y554/614/674에 배치된다. 세 외곽은 358×48px이며 12px 간격과 모서리 설정 32px을 갖는다. 48px 높이에 맞춘 SVG의 실제 둥근 외곽은 반지름 24px로 렌더된다. 첫 렌더에서 Apple 자산의 사각 코너가 둥근 외곽에서 보였다. 최종 렌더는 공식 표식·레이블 픽셀을 유지한 채 네이버와 Apple을 외곽에 마스킹했다. 최종 캡처에서 Apple 외곽 밖에 검은 사각 영역이 보이지 않는다.
- ‘한강’ 레이블 색을 원본 `#BBCFC8`에서 같은 지명 팔레트의 `#C3D3CA`로 올렸다. 실제 캡처의 글자 위치에서 측정한 최소 대비는 4.41:1에서 4.62:1로 개선됐다. Apple의 1px 경계 폭은 유지하고 `#5E6D63`에서 `#68786E`로 밝기를 조정했다. 위쪽 가운데 경계와 인접 지도 대비는 2.94:1에서 3.44:1로 개선됐다. [렌더 보고서](render-report.json)
- 제목 두 줄은 각각 최소 12.81:1과 9.51:1, 부제 8.11:1, 약관 9.72:1이다. 제공자 레이블은 카카오 13.75:1, 네이버와 Apple 각 21:1이다. 390×844의 정적 상하 표시 영역과 콘텐츠 경계를 확인했다. 소셜 외곽의 가로와 세로는 각각 44px 이상이다. [렌더 보고서](render-report.json)
