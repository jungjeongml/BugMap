## 화면 적용

- **레이아웃.** 로고 → 두 줄 소개와 부제 → 지도 관찰 예시 → 소셜 버튼 → 약관 순서로 읽힌다. 390×844의 상단 44px·하단 34px는 캡처 기준이다. 앱에서는 기기 인셋을 읽어 적용한다. 작은 화면이나 큰 글자 설정에서는 세로 스크롤로 버튼과 약관의 잘림을 피하고, 가변 폭에서도 터치 영역을 최소 44×44로 확보한다. 기기별 확장은 구현 시 검증한다.
- **텍스트.** 제목은 34px, 부제는 14px, 약관은 11px가 기준이다. 서체와 행간은 토큰과 실제 Figma를 대조한다. Figma에서 적용된 Apple SD Gothic Neo와 SVG 미리보기의 글자 폭은 조금 다르므로 한글 줄바꿈을 기기에서 확인한다.
- **동작.** 정적 화면의 세 버튼은 인증 진입점의 레이블을 보여 준다. 제품에서 제공자를 확정한 다음 탭을 공식 인증 흐름에 연결하고 취소 시 로그인 화면 복귀를 검증한다. 성공 이동·실패 재시도·약관 링크는 [상태와 흐름](../03-structure/flows.mmd) 및 [제품 TDD](../../../docs/TDD.md#61-모바일-앱-로그인세션)를 참고한다.
- **접근성.** 활성화된 버튼에 제공자 이름을 포함한 접근성 레이블과 버튼 역할을 부여한다. 장식 지도와 관찰 도형은 스크린리더에서 숨기고, 제목·버튼·약관의 읽기 순서를 직접 확인한다. 앱 일반 아이콘은 프로젝트 Lucide 컴포넌트, 제공자 표식은 공식 자산을 사용한다.
