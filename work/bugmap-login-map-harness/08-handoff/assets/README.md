# 05 로그인 전달 자산

아래 파일은 승인된 디자인 시스템의 바이트를 그대로 복사했다. 해시는 [핸드오프 매니페스트](../manifest.json), 취득 경로와 처리 과정은 [원본 자산 출처](../../05-design-system/asset-sources.md)에서 확인한다.

| 파일 | 사용 |
|---|---|
| [map-background.png](map-background.png) | 390×844 장식 지도와 상하 페이드. |
| [bugmap-logo-vector-lime.svg](bugmap-logo-vector-lime.svg) | 배경 없는 `#C5EE79` BugMap 로고. |
| [kakao-login.svg](kakao-login.svg) | 카카오 심볼과 레이블을 추적할 공식 한국어 완성형 자산. |
| [naver-content.png](naver-content.png) | 흰 외곽에 표시한 네이버 표식·레이블의 560×112 자산. 기준 표시 크기 140×28. |
| [naver-login.png](naver-login.png) | 승인 시안에 사용한 네이버 콘텐츠의 원본 PNG. |
| [apple-login.png](apple-login.png) | Apple 한국어 2배율 버튼 자산. 기준 표시 크기 358×48. |
| [lucide-license.txt](lucide-license.txt) | 관찰 표식에 사용한 Lucide의 라이선스. 앱에서는 프로젝트 아이콘 컴포넌트를 사용한다. |
