# BugMapHaness 05 첫 로그인 / 지도 배경

지도에서 곤충을 기록하는 앱임을 첫 화면에서 바로 이해하고, 소셜 로그인 방법을 고를 수 있게 한다. 이미 디자인한 [BugMap 05 원본](https://www.figma.com/design/LynbxdW8Qf7TavCrPLd2nY/BugMap?node-id=134-1239)을 기준으로 BugMapHaness에 검수 가능한 버전을 만든다.

## 제작 범위

- 모바일 한국어 기본 로그인 `login/default` 한 장을 390×844로 구성한다. 새 상태 화면, 실제 인증, 지도 SDK 연동은 별도 범위다.
- 다크 지도 삽화가 화면 끝까지 이어지고 로고 위쪽과 버튼 아래쪽은 자연스럽게 페이드된다. 지도 삽화의 관찰 지점과 라벨은 원본의 로그인 소개 맥락을 유지한다.
- 배경 없는 `BugMap-logo-vector`를 연두색 `#C5EE79`로 표시한다. 소개 제목·부제, 지도 삽화, 카카오·네이버·Apple 순서, 약관 안내를 원본과 대조한다. 기준 크기에서 소셜 로그인 버튼은 358×48이고, 노드의 모서리 설정은 32px이다. 터치 영역은 최소 44×44로 확보한다.
- 지도 삽화·상하 페이드는 출처와 해시를 등록한 배경 PNG 레이어로 두고 교체할 수 있게 한다. 현 하네스의 채우기 검사 범위를 고려한 방식이며 페이드의 정지점은 이미지에 포함한다. 벡터 로고, 주요 문구, 버튼 외곽, 약관은 편집 가능한 레이어로 구성하고 콘텐츠 컨테이너에는 오토레이아웃을 적용한다. 공식 제공자 이미지 자산의 출처를 기록하고 일반 UI 아이콘은 Lucide를 기준으로 한다. 원본 안에 들어 있는 별도 작업 프레임 06은 범위에서 제외한다.
- TalkToFigma MCP의 원본 채널 `6jgzxrx1`은 읽기 기준이다. 대상 채널 `y5fz18ft`의 BugMapHaness에 프레임 한 장을 추가하며 기존 `02 · 메인 / 발견 지도` 프레임을 보존한다.

## 수용 기준

[요구사항 표](requirements.csv)를 기준으로 원본 캡처와 결과 캡처에서 구성, 문구, 색, 대비, 잘림·겹침, 안전 영역, 버튼 크기를 확인한다. 결과 프레임의 노드 ID와 구조 조회, 캡처, 검사 결과를 하네스에 연결한다. 접근할 수 없거나 검증하지 못한 항목은 검수 기록에 남긴다.

[2026-11-19 원본 캡처](evidence/bugmap-05-source.png)와 [원본 노드 조회](evidence/source-05-tree.json)를 기준으로 삼는다. [대상 조회](evidence/target-document.json)에서 Page 1과 기존 프레임을 확인했다. 사용자가 제공한 [BugMapHaness 링크](https://www.figma.com/design/Dan8qlRM20XPkk7Mtd5riw/BugMapHaness?node-id=0-1)의 파일 키와 대상 페이지를 [대상 설정](../control/figma.json)에 고정했다.
