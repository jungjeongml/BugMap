# PRD 독립 비평

원본 PNG를 열어 390×844 치수와 시각 구성을 확인한 별도 읽기 전용 검토 기록이다.

> PRD 독립 비평 핵심은 blocked입니다. 원본 PNG 직접 열었고 SHA-256 71cd76a4…22319f 일치, 390×844, 연두색 무배경 로고·자연스러운 양끝 지도 페이드·카카오/네이버/Apple·약관 확인했습니다. `control/figma.json:2,22` fileKey=null이고 PRD:17에서 공유 링크 대조·확정을 승인 전 조건으로 명시했습니다. 대상 응답은 Page 1 및 7:2까지만 증명하며 정식 파일 식별을 대체할 수 없습니다. 중요 수정은 PRD:9–10/CSV LOGIN-05-04·05에 Lucide 일반 아이콘/제공자 공식 자산 규정과 편집 범위를 명시하는 것입니다. 원본 지도 `142:712`와 네이버/Apple 버튼 자산이 IMAGE fill이므로 모든 글자/지도 벡터 편집으로 읽히지 않게 외곽과 주요 텍스트는 편집 가능, 허용 공식 이미지/지도는 독립 이미지 레이어·출처 매핑으로 정의하세요. 수용 조건에서 원본 버튼 358×48(각 인스턴스) 크기와 radius=32는 노드 속성 검증임을 명시하면 재현 검수 정밀도가 올라갑니다. `get_node_tree` 미지원은 대상 7:2 조회 성공과 별개이며 최종 원격 내보내기 대체 경로 실증은 아직 미검증입니다.

검토 후 버튼 노드 수치, 자산·Lucide 규칙과 레이어 편집 범위를 요구사항에 반영했다. 대상 키와 전체 노드 검증 경로는 미확인 상태다.

## 추가 확인 원문

> 추가 중요 충돌을 확인했습니다. 원본 138:743의 편집 가능한 390×844 페이드 레이어가 실제 `GRADIENT_LINEAR`(7 stops)이며 `tools/design-harness/figma.mjs:43`은 SOLID/등록 IMAGE 외 모든 fill을 unsupported-fill 처리하고 :75에서 검증을 막습니다. PRD:8–10/LOGIN-05-02에 이 제약과 검증 경로 결정을 명시해야 합니다. 원본 페이드가 편집 가능한 그라디언트여야 한다면 공식 lint 지원이 필요하고, 독립 등록 PNG가 요구 범위에 부합할 경우에만 지도/페이드 층을 승인된 자산으로 구현할 수 있습니다. 또한 원본 레이아웃 134:1239는 NONE이나 모든 결과 FRAME은 :49상 auto-layout이어야 해 원본 전체 복제와 동일시하면 통과하지 않습니다. `target-existing-map.json` 7:3 IMAGE 응답에는 imageHash가 실제 누락되어 get_node_info만으로 최종 raw export 계약 충족도 증명되지 않습니다.

사용자가 제공한 파일 링크를 대상 설정에 반영했다. 원본 페이드를 등록 PNG 배경으로 보존하고 편집 가능한 콘텐츠를 오토레이아웃으로 구성하는 기준을 추가했다. 전체 노드 내보내기 검증은 남아 있다.
