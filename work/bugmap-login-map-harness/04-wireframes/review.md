## 배치 기준

1. 지도 자리표시자는 x0, y0에서 390×844 전체를 채운다. 원본에서 지도는 상단 로고와 하단 버튼 뒤까지 이어지고 양 끝에서 어두워진다. 다크 지도·페이드의 실제 이미지는 후속 승인 단계에서 출처와 해시가 있는 배경 자산으로 확인한다.
2. 상단 시스템 표시 아래 중앙의 로고 슬롯은 x131, y72, 128×39.68이다. 슬롯 윤곽은 배치 검토용이며 대상의 벡터 로고는 배경 없이 배치한다. 소개 제목은 「오늘 만난 곤충을」과 「지도에 남겨요」로 두 줄을 유지하고, 이어서 「사진으로 기록하고, 주변의 발견을 살펴봐요.」를 한 줄로 둔다.
3. 관찰 삽화는 y304부터 이어진다. 서울숲·성수동·한강의 상대 위치, 관찰 경계, 세 지점과 중앙 곤충 표식, 오른쪽의 「넓적사슴벌레」와 「서울숲 관찰 기록」을 표시한다. 경계, 지점 및 제공자 표식은 회색 자리표시자로 렌더한다. 관찰 카드는 지도 위에서 표식 오른쪽에 놓인다.
4. 버튼 세 개의 좌우 여백은 16px이고 외곽은 각각 358×48px이다. 카카오 y554, 네이버 y614, Apple y674 순이다. 원본 PNG에서 각 버튼의 윗경계와 12px 간격을 확인했다. 원본 노드 `134:1240`의 총높이 168px와 자식 높이 48px 세 개도 일치한다. 승인 모서리 설정은 32px이며 CLI의 SVG는 버튼에 고정 12px 반경을 적용한다.
5. 약관은 「계속하면 이용약관 및 개인정보 처리방침에 동의합니다.」 한 줄을 y742~774의 배치 블록에 둔다. 상단 y0~44와 하단 y810~844는 이 와이어프레임에서 시각적으로 구획한 시스템 영역이다. 원본의 홈 인디케이터가 차지하는 x128, y827, 134×4를 반영했다.

## 실제 렌더와 검수

기본 권한의 실제 `wireframe` 실행은 Chromium 종료 오류로 코드 2를 반환했다. 조정자가 로컬 렌더를 다시 실행해 코드 0으로 SVG·PNG를 생성했다. 원본 PNG와 첫 렌더를 직접 열어 비교하니, 원본 곡선 대신 관찰 영역의 경계 상자를 그린 와이어프레임에서 밑변과 「한강」 글자가 겹쳤다. 와이어프레임에서만 해당 글자 블록을 9px 내리고, 렌더러의 고정 14px 글자 폭에 맞춰 제목·부제·약관과 제공자 표식·레이블 묶음의 중앙 정렬을 다듬었다.

조정자가 `wireframe --force`로 재렌더한 시각은 2026-11-19 16:52:21 KST다. 재생성한 [390×844 PNG](captures/login/default.png)를 직접 열어 「한강」이 경계선 아래에 읽히는 점, 제목 두 줄과 지도·약관 레이블에 잘림이 없는 점, 버튼 세 개와 홈 인디케이터가 겹치지 않는 점을 확인했다. 기준 화면에서 로그인 선택지가 모두 프레임 안에 보인다. 관찰 경계 상자 안에 지점과 곤충 표식이 있고 기록 카드는 그 오른쪽에 있어, 지도와 카드의 겹침은 원본의 레이어 관계를 나타낸다. 상단 표시와 로고 사이, 약관과 하단 표시 사이에 각각 여백을 확인했다.

## 남은 검증

실제 지도·상하 페이드, 최종 색상과 대비, 로고 벡터와 제공자 공식 자산, 얇은 버튼 경계 및 원격 Figma 편집 속성은 후속 단계에서 검수한다. 이번 정적 기준 화면으로는 실제 기기 안전 영역, 다른 화면 크기와 글자 확대, 스크롤, 탭·인증·정책 링크, 스크린리더를 확인하지 않았다. 디자인 시스템 단계는 와이어프레임에 대한 사람 승인 이후 시작한다.
