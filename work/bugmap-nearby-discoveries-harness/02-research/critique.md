# 리서치 독립 비평

**2단계 리서치 · `ready`.** 검토한 산출물은 화면 구조 단계에 넘길 수 있다.

- 정식 PRD와 NEAR-01~06의 SHA-256을 승인 `9e02aa07-23ee-4e87-8530-39e1f406f67b`와 대조했다. 리서치 문서 3개와 JSON 2개를 읽고 Kyro, 기존 BugMap 지도, Apple 시트 PNG를 직접 열었다. 세 PNG 해시는 출처 기록과 일치했다. 확장 높이와 손잡이 설명은 공식 본문에서 확인했다. [Apple HIG · Sheets](https://developer.apple.com/design/human-interface-guidelines/sheets)
- 경미한 지적은 Kyro 캡처의 가로 사진을 ‘대형 세로 사진’으로 기술한 점이다. 이를 ‘큰 가로 사진’으로 고쳤다.
- 관찰·제안·미검증을 구분했다. Kyro 코스 길이 구간과 BugMap의 공개 좌표 기준 누적 반경을 구분하고, 41:81 손잡이 진입과 ‘지도 보기’ 복귀, 지도 탭 단독 선택, 3 km 경계 포함을 구조 검토에 연결했다.
- 스크롤 중 버튼 고정, 제스처, 검색·GPS, 접근성, 실제 프로토타입과 노드 보존은 후속 검증 범위다.
