# 구조와 와이어프레임에 넘길 근거

| 요구사항 | 관찰에서 도출한 제안 | 비교할 실마리 |
| --- | --- | --- |
| NEAR-01 | 기존 41:81의 손잡이에서 펼치고, 확장 패널에서도 손잡이를 표시한다. 아래쪽에서 항시 접근 가능한 ‘지도 보기’를 탭 영역과 함께 고정하고 목록만 그 위에서 스크롤한다. | 목록이 마지막까지 버튼에 가리지 않게 스크롤하고 지도 복귀 후 기존 지도 노드에 돌아온다. 두 상태 모두 복귀 위치와 라벨이 같다. |
| NEAR-02 | 검색을 손잡이 다음 첫 조작부에 두고 거리 선택과 목록을 이어 배치한다. 검색 문구는 기존 곤충·지역 검색 패턴을 사용한다. | 390px에서 검색·거리 행·기록 순서가 드러나고, 검색 적용·취소·빈 결과 및 검색과 반경 동시 적용을 흐름과 상태표로 확인한다. |
| NEAR-03 | ‘전체 · 1 km 이내 · 3 km 이내 · 5 km 이내’를 한 번에 하나만 선택한다. ‘전체’는 반경 제한 해제로 설명한다. 3 km 안쪽·경계(3.0 km)·바깥 예시로 두 화면에서 건수 변화와 복구를 확인한다. | 거리에는 현재 위치에서 공개 좌표까지의 직선거리를 사용한다. 위치를 못 확인하면 기록의 거리 표기를 생략하고, 반경을 고를 때 위치 확인 필요를 안내한다. 양방향 지도 이동 시 같은 중심과 반경, 전체·위치 미확인 시 지도 경계 숨김을 구조로 확인한다. |
| NEAR-04 | Kyro의 사진 중심 기록 탐색을 더 작은 곤충 사진 썸네일과 메타데이터로 적용한다. 한 항목에 곤충명, 관찰·채집, 공개 지역, 실제 발견 일시와 거리 정보를 모아 두 기록 유형을 비교하기 쉽게 한다. | 390×844 첫 화면에서 여러 기록을 훑도록 사진·카드 높이를 정한다. 출처가 확인된 예시 사진은 디자인 시스템에서 확정한다. 상세 진입과 복귀는 흐름에서 검수한다. |
| NEAR-02·04 | 초기 목록 정렬은 실제 발견 일시의 최신순을 구조 단계에서 우선 검토한다. 반경을 바꾸면 조건에 맞는 기록만 남기고 같은 정렬 기준을 적용한다. | 기록마다 실제 발견 일시를 보여준다. 별도 정렬 조작부는 PRD 범위에 지정돼 있지 않으며, 이 제안은 새 정렬 기능을 요구하지 않는다. 조회 영역의 상세 결정은 기존 지도 영역 정책과 함께 구조 단계에서 다룬다. |
| NEAR-05 | 기존 다크 패널과 지도·커뮤니티·채팅·마이 탭을 활용한다. 지도 탭의 선택 표시와 ‘지도 보기’의 복귀 역할을 구분한다. | 두 확장 상태의 네 탭 순서와 지도 단독 선택이 같다. 텍스트와 선택 모양이 읽히며 모든 조작 영역이 44×44px 이상이다. |
| NEAR-06 | Figma에서는 `default` ↔ `radius-3km`와 기존 메인 지도 사이의 흐름을 대표로 확인한다. | 390×844 두 상태에서 카드·하단 버튼·탭이 가리지 않는지 대조한다. 현재 화면의 실기능과 Figma 노드 보존은 제작 및 검수 단계에서 확인한다. |

정렬, 카드 높이, 예시 자산은 승인 범위 안의 구조 제안이다. 실제 검색·GPS·보존된 필터 상태·목록 조작을 리서치에서 실행하지 않았다.
