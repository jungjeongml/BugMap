# 내 주변 발견 제작 도구

Stage 05 원본과 승인 기록, 목표 파일 및 기존 메인 지도 손잡이를 대조한 뒤 등록된 Cursor MCP Plugin의 명령 라우터에 프로젝트 전용 제작 명령을 임시로 붙이는 절차다. 새 플러그인 등록은 필요하지 않다. 기본 도구가 로컬 작업용 메모 안의 연결 상태를 사용하는 경우, 실행 전 현재 연결과 목표 노드를 다시 확인한다.

- `prepare.mjs`는 승인된 레이아웃·텍스트·아이콘·사진 출처를 바탕으로 `plan.json`을 만든다. 어댑터 인자는 임시 작업용으로만 사용한다.
- `plugin.js`는 편집 가능한 프레임·컴포넌트·변수·이미지 채우기를 만들고 네이티브 노드·PNG를 내보낸다. 기존 손잡이에서 다른 연결을 읽어 보존하면서 새 드래그 연결을 추가한다.
- `draw.mjs`는 승인과 현재 목표를 대조하고 로컬 연결을 통해 `status`, `baseline`, `build` 또는 `export`를 요청한다. 상태 조회를 먼저 하며 중복 제작을 차단한다.
- `inspect-captures.mjs`는 승인 Chromium PNG와 실제 Figma PNG의 영역별 차이를 계산한다. 캡처의 눈으로 본 검수는 별도다.
- `mock-test.mjs`는 모의 노드 환경에서 대상 가드, 연결 다섯 개, 중복 방지, 실패 복구를 확인한다. 실제 원격 확인과 구분한다.

변경 전 로컬 플러그인 원본 바이트를 별도 임시 폴더에 보관한다. 실행 후 원본과 바이트 일치를 확인해 임시 동작과 임시 채널을 복원한다. 실행용 어댑터에는 원본 PNG의 바이너리와 외부 플러그인 파일이 합쳐지므로 저장소 산출물에는 포함하지 않는다.
