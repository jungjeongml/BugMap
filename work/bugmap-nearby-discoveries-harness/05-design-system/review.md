## 적용과 배치

- 기존 메인 지도와 같은 다크 패널, 검색 필, 연두색 강조, 4개 탭과 Lucide 도형을 가져왔다. 손잡이 밑으로 검색, 거리, 목록 제목과 결과 수, 기록을 배치했다. [기존 지도 캡처](../../bugmap-main-map-harness/05-design-system/captures/390x844-default.png) · [색상과 문구 명세](DESIGN.md)
- 네 거리 칩은 46px 높이이며 선택된 항목에는 밝은 윤곽, 짙은 초록 면과 굵은 레이블을 적용했다. 화면에서 지도 탭이 선택된 채로 유지된다. ‘지도 보기’는 148×48px의 고정 버튼이다.
- 카드마다 88×88px 사진과 넓적사슴벌레·왕잠자리·칠성무당벌레 이름, 관찰·채집 레이블, 공개 지역, 발견 일시, 거리를 배치했다. 예시 3개는 실제 발견 일시 기준의 내림차순을 보여준다. 3 km 이내에서는 4.6 km 왕잠자리 항목이 빠지고, 정확히 경계인 3.0 km 칠성무당벌레가 0.8 km 넓적사슴벌레와 함께 남는다. 위치·일시·거리는 시안용 값이다. [사진 출처와 사용 조건](asset-sources.md)
- 116px 높이로 반복되는 기록 카드와 88px 썸네일의 모서리는 각각 20px와 13px로 설정했다. 작은 썸네일에서 사진 가장자리가 잘리는 면적을 줄이고 여러 장을 연달아 볼 때 카드 경계를 유지하기 위해 이 목록에서만 적용한다. 패널과 개별 기록 상세에는 이 예외를 적용하지 않는다. [공통 모서리 기준](../../../docs/DESIGN.md#shapes)
- 목록 전용 영역은 y=248–690이고 하단 고정 영역은 y=690–844다. 기본 상태의 마지막 카드는 y=626까지이고 3 km 이내는 y=498까지다. 두 상태 모두 목록과 고정 버튼을 구분하고 54px/34px 안전 영역을 반영했다.

## 화면 너비와 접근성

- 실제 앱에서 기기별 상단·하단 안전 영역 값을 사용한다. 검색과 카드는 사용 가능한 너비에 맞춰 늘거나 줄인다. 좁은 화면이나 큰 글자에서는 곤충명과 메타데이터를 줄바꿈하고 카드 높이를 늘려 정보를 유지한다. 거리 칩이 한 줄에 맞지 않으면 최소 44×44px 조작 영역을 유지한 채 가로로 스크롤한다.
- ‘지도 보기’와 하단 탭은 목록의 스크롤 영역 밖에 둔다. 하단 안전 영역과 글자 배율을 반영해 푸터 높이가 달라지면 목록의 사용 가능 높이도 갱신한다.
- 스크린 리더는 카드마다 곤충명, 관찰·채집 유형, 공개 지역, 발견 일시와 표시되는 거리를 하나의 기록 열기 조작으로 읽는다. 거리 칩과 하단 탭은 이름과 선택 상태를 전달한다.
- 이 규칙은 제품 적용 기준이다. 다른 화면 크기, 시스템 글자 배율 및 스크린 리더는 실제 기기에서 확인한다.

## 재현과 후속 검증

저장소 루트에서 `node work/bugmap-nearby-discoveries-harness/05-design-system/build.mjs`로 두 SVG와 자산 해시를 생성하고, `node work/bugmap-nearby-discoveries-harness/05-design-system/render.mjs`로 캡처를 생성한다. 두 명령 모두 스테이징 디렉터리에서 실행할 때 첫 인수로 기존 저장소 루트를 받을 수 있다. 캡처 검사는 설치된 Chromium, 기존 하네스의 CDP 도우미 및 저장소 `pngjs`를 사용한다. [빌드 소스](build.mjs) · [측정 소스](render.mjs)

현재 증거는 두 시각 시안에 해당한다. 기존 Figma 지도 손잡이 연결과 지도 보기 양방향 이동은 디자인 시스템 승인 후 제작·확인한다. 검색 적용·취소, 위치 확인·권한 복구, 실제 거리 계산과 반경 공유, 빈 목록·오류·상세 진입 및 실제 스크롤은 제품 구조에 명시하며 후속 검증 범위로 유지한다. Figma에서 기존 지도 탭 글꼴과 사용 가능한 폰트를 확인하고, 시안과의 차이가 생기면 검수에 기록한다. [구조와 상태](../03-structure/states.csv)
