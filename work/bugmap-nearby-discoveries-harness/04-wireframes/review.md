## 배치와 예시 데이터

| 요소 | 이번 구조에서 검토할 기준 |
| --- | --- |
| 손잡이·검색·거리 | 상단 안전 영역 54px 다음에 44px 높이의 손잡이 조작 영역, 358×48px의 곤충·지역 검색창, 높이 46px의 거리 칩 네 개 순서다. 선택 칩만 밑줄로 표시한다. |
| 목록 | 목록 영역은 y=248부터 y=690까지 세로로 스크롤하는 구조다. 카드 높이 116px와 카드 간격 12px를 기준으로 왼쪽 88×88 썸네일과 오른쪽 곤충명·관찰/채집 유형·공개 지역·발견 일시·거리를 배치했다. |
| 지도 보기·탭 | y=690부터 하단 고정 영역을 분리한다. 148×48px ‘지도 보기’ 아래로 지도·커뮤니티·채팅·마이 탭을 두며 지도만 밑줄 표시한다. 탭 높이는 52px이고 하단 안전 영역은 34px다. |
| 전체 | 0.8 km 넓적사슴벌레 관찰, 4.6 km 왕잠자리 관찰, 3.0 km 칠성무당벌레 채집의 세 기록이다. 목록은 열 때의 지도 영역에서 시작하고 ‘전체’는 반경만 해제한다. |
| 3 km 이내 | 3 km 안쪽의 0.8 km와 시연에서 정확히 3000m인 3.0 km가 남는다. 4.6 km의 바깥 기록이 빠진다. 기록 이름·사진 자리·발견 일시·거리 값은 가상 예시다. |

정렬은 실제 발견 일시의 최신순으로 정했다. 반경을 바꿔도 남은 기록은 같은 정렬을 쓴다. 지역 검색으로 조회 영역이 바뀌어도 반경을 적용할 때 기준점은 기기의 현재 위치다. 거리를 표시할 때는 반올림하고, 반경 포함 여부는 공개 좌표까지의 실제 직선거리로 결정한다. [리서치 적용 제안](../02-research/recommendations.md) · [지도 TDD](../../../docs/TDD.md#지도-표시와-내-주변-반경)

## 검수 결과

- 하네스 CLI로 입력 JSON에서 [전체 SVG](nearby-discoveries/default.svg), [3 km 이내 SVG](nearby-discoveries/radius-3km.svg)와 PNG를 생성했다. 실제 생성된 PNG 두 장을 직접 열어 검색·거리·목록의 순서, 네 칩의 한 줄 표기와 선택 표시, 두 종류의 기록, 고정 지도 복귀와 네 탭을 확인했다. 글자 잘림이나 목록과 고정 영역의 겹침은 보이지 않았다. [생성 보고서](wireframes-report.json)
- 입력과 거리 칩·기록 카드·지도 보기·탭 및 손잡이 조작 영역은 각 상태에서 최소 44×44px이며 서로 겹치지 않는다. 기본 화면의 마지막 카드는 y=626까지, 반경 상태의 마지막 카드는 y=498까지다. 두 상태 모두 고정 영역이 시작되는 y=690 위에 해당한다.
- 처음 브라우저 실행이 샌드박스에서 종료되어 임시 Chromium을 허용한 실행으로 재시도했고 캡처가 생성됐다. 스크롤과 고정 영역은 정적 배치 및 문서에 근거해 검토했다.

| 요구사항 | 확인 내용 |
| --- | --- |
| NEAR-01 | 기존 41:81의 손잡이 41:451에서 확장 화면으로 진입하고 두 상태 모두 기존 지도로 돌아가는 흐름을 명시했다. ‘지도 보기’ 위치와 크기는 두 캡처에서 같다. |
| NEAR-02 | 검색 → 거리 → 기록 목록 순서와 제목을 확인했다. 검색 적용과 취소 후 복귀, 빈 결과 및 조건 조합은 구조에 명시했다. |
| NEAR-03 | 전체 3개에서 3 km 이내 2개로 줄며 경계 3000m 예시가 남는다. 양방향 이동에서 같은 현재 위치 중심과 반경을 유지하는 제품 흐름, 권한 복구, 전체·위치 미확인에서의 지도 경계 숨김을 기록했다. |
| NEAR-04 | 기록 카드에 사진 자리와 곤충명, 관찰·채집, 공개 지역, 발견 일시, 거리가 보인다. 기존 상세로 이동하고 스크롤과 필터를 유지한 목록으로 돌아오는 흐름을 기록했다. |
| NEAR-05 | 기존 검색 문구와 네 탭을 확인했다. 지도만 선택 상태다. 색상과 사진은 디자인 시스템 단계에서 검토한다. |
| NEAR-06 | 화면 구조의 두 승인 대상과 390×844 SVG·PNG 두 상태가 일치한다. 원격 Figma 노드 및 기존 지도 보존 검증은 제작 후 진행한다. |

실제 Figma 프로토타입과 네이티브 스크롤·검색·거리 계산·GPS 권한·상세 화면·기기별 안전 영역은 미검증이다. 두 대표 시안에서 확인할 전환은 구조 문서에 표시했다.
