# BugMapHarness 내 주변 발견

로그인한 사용자가 메인 지도의 패널을 위로 드래그해 주변의 공개 곤충 기록을 목록으로 확인한다. 여러 기록을 한 번에 훑고, 곤충이나 지역으로 검색하거나 현재 위치에서 가까운 기록을 골라볼 수 있게 한다.

## 화면과 흐름

- [BugMapHarness 메인 지도 41:81](https://www.figma.com/design/Dan8qlRM20XPkk7Mtd5riw/BugMapHarness?node-id=41-81)의 기존 손잡이에서 ‘내 주변 발견’으로 진입한다. 목록을 스크롤해도 보이는 ‘지도 보기’를 누르면 기존 메인 지도로 돌아간다. 목적지는 같은 Page 1에 추가한다.
- 상단 손잡이 다음 첫 조작부는 기존 곤충·지역 검색창이다. 그 아래에 거리 선택 버튼을, 이어서 스크롤 가능한 공개 관찰·채집 기록 목록을 둔다. 화면 이름과 네 탭은 BugMap의 기존 지도 흐름과 연결한다.
- 거리 선택안은 ‘전체’, ‘1 km 이내’, ‘3 km 이내’, ‘5 km 이내’다. 반경을 선택하면 현재 위치에서 공개 위치까지의 직선거리가 해당 값 이하인 기록을 보여준다. ‘전체’는 반경 제한을 해제한다. 지도와 목록을 오갈 때 같은 현재 위치 중심과 반경을 유지한다. 지도에는 반경을 적용했을 때만 경계가 보인다. ‘전체’ 또는 위치 미확인 상태에서는 경계를 숨기고, 위치가 없을 때 반경을 선택하면 위치 확인이 필요하다고 안내한다.
- 각 카드에는 곤충 사진, 곤충명, 관찰 또는 채집 유형, 공개 지역, 실제 발견 일시를 표시한다. 현재 위치를 확인할 수 있으면 공개 위치까지의 거리를 보조로 표시한다. 목록에서 기존 기록 상세로 들어가는 동작을 설계한다.
- Figma 산출물은 한국어 390×844의 확장 기본 화면과 대표 ‘3 km 이내’ 상태다. 기존 메인 지도에서의 드래그 진입, ‘지도 보기’ 복귀, 대표 거리 선택과 전체 선택 복귀를 Figma에서 확인한다. 지도·목록의 중심과 반경 공유, 위치 권한 복구, 검색 적용·취소, 기존 상세 진입·복귀는 화면 구조 단계의 흐름과 상태표에 명시하고 최종 검수에서 대조한다. 별도 상세 화면이나 실제 기능 구현은 후속 범위다.

## 리서치 가정과 미결정

[Kyro 첨부 화면](evidence/kyroScrollMenu.png)은 검색·거리 선택·이미지가 있는 목록 순서, 고정된 지도 복귀의 참고 자료다. 현재 [메인 지도 시안](../../bugmap-main-map-harness/06-figma/captures/main-map-default.png)의 색과 탭, 검색 시작점을 이어받는다. 사진 정보량과 카드 높이, 거리 선택안의 한 줄 가독성은 와이어프레임에서 확인한다. 실제 기록 사진·이름·거리 대신 예시 자산과 값을 사용한다. 정렬 방식은 리서치 후 화면 구조 단계에서 정하고, 사진 자산은 출처와 사용 범위를 확인해 디자인 시스템 단계에서 정한다.

## 검수 기준

[수용 기준](requirements.csv)을 Figma 노드·390×844 캡처·프로토타입과 대조한다. 검색·거리 버튼·기록 카드·지도 복귀 영역의 가독성과 최소 44×44px 조작 영역을 확인한다. 메인 지도에서 필요한 프로토타입 연결을 추가하기 전후로 기존 화면의 모양·구조와 다른 프로토타입 연결을 대조한다.
