# PRD 독립 비평

## 첫 검토

**판정 `needs_revision`.** 요청한 화면 순서와 메인 지도 연결이 반영됐다. 제품의 반경 동작과 검색·상세 진입·권한 복구를 수용 기준에 옮겨야 한다.

- 검토 SHA-256은 PRD `b35851745a4c24f7c8863990f2f3ba8f561fc99c74183386d817496cd7907ced`, 요구사항 `c1ec39529d0ec860f66030ecb0036622cbbf00de24cc576277d4c5855c5b0c5d`, 첨부 `126cb82cd467621a948b3a6c58b97303bc37a869e991481612275bc6a82d2beb`다. 기존 문서와 메인 지도 캡처 8개의 해시가 일치했고 참고 PNG 두 장을 직접 열었다.
- **중요 · NEAR-03.** 기존 MAP-10에 맞춰 지도와 목록의 같은 중심·반경, 양방향 이동 시 조건 유지와 지도 경계의 표시·해제 기준을 명시한다. 대표 3 km 선택과 전체 복귀, 기존 지도 노드 복귀는 Figma 상의 범위다.
- **중요 · NEAR-02~04.** 검색·상세 진입·권한 복구를 구조 단계 흐름·상태표로 검증한다. 관찰과 채집 예시를 각각 보여주고 기록 선택 후 상세 진입 흐름을 명시한다.
- **경미.** 스크롤 중 지도 복귀 접근을 수용 기준에 반영한다. 정렬과 조회 범위, 예시 사진 자산의 결정 시점을 남긴다.

검색 → 거리 선택 → 공개 곤충 기록 목록의 순서, BugMap 다크 스타일, 기존 메인 지도 복귀, 공개 좌표 기준과 변경 전후 보존 검수는 요구사항에 부합했다. 실제 Figma 노드·프로토타입 조작과 실기기 기능 검증은 후속 범위다.

## 반영

양방향 중심·반경 유지 및 경계 조건, 검색·상세·권한 복구 산출물, 두 기록 유형 예시와 지도 복귀 조건을 반영했다. 정렬과 예시 자산을 결정할 단계를 기록했다.

## 최종 검토

**판정 `ready`.** PRD에서 사용자 요청이나 기존 메인 지도 명세와 충돌하는 차단·중요 이슈는 없었다. 사람 승인 전 독립 검토 결과다.

[Kyro 첨부](evidence/kyroScrollMenu.png)와 [기존 지도 캡처](../../bugmap-main-map-harness/06-figma/captures/main-map-default.png)를 직접 열었다.

검색창 → 거리 버튼 → 기록 목록 순서와 스크롤 중 접근 가능한 ‘지도 보기’가 첨부의 흐름을 반영한다. 기존 메인 지도 `41:81` 및 손잡이 `41:451` 연결과 지도·목록 간 현재 위치 및 반경 공유는 기존 인계서와 제품 요구사항에 부합한다.

화면 구조 단계에서는 검색과 반경을 함께 적용했을 때의 결과, 결과가 없을 때의 안내와 검색 조건 삭제·‘전체’ 복귀를 상태표에서 확인한다. 원격 Figma 노드, 프로토타입 전환, 실제 기기 동작은 후속 검수 대상이다.
