### 탐색 상태 및 데이터

- 지도와 목록에서 같은 현재 위치 중심·선택 반경을 사용하고 ‘지도 보기’ 뒤 다시 열어도 유지한다. ‘전체’는 현재 열린 지도 범위의 반경 제한을 해제하고 검색 조건을 유지한다. 지도에서는 반경이 적용됐을 때만 연두색 원형 경계를 표시한다.
- 현재 위치에서 기록의 공개 위치까지의 직선거리를 미터 단위로 계산한다. 거리가 선택 반경 이하인 기록을 포함하며, 3000m는 ‘3 km 이내’에 포함된다. 지도·목록·거리 표시에 공개 좌표를 사용한다. 공개 정책은 [제품 PRD](../../../docs/PRD.md)와 [지도·반경 TDD](../../../docs/TDD.md#지도-표시와-내-주변-반경)를 따른다.
- 현재 위치를 확인할 수 없을 때 거리 선택은 위치 확인 안내로 이어진다. 확인에 성공하면 요청한 반경을 적용한다. 권한 거부·취소·실패 시에는 전체 목록을 제공하고 카드 거리와 지도 원형 경계를 숨긴다. 허용과 거부 상태 모두 ‘지도 보기’에 접근할 수 있게 한다.
- 검색 결과의 곤충 또는 지역 조건과 반경은 함께 적용한다. 지역 결과가 조회 영역을 갱신해도 거리 기준은 현재 위치다. 검색을 취소하면 직전 검색·반경·스크롤 위치를 복원한다. 검색 조건 삭제는 반경을 유지한다. 목록에서 상세를 열고 뒤로 돌아오면 목록 조건과 스크롤 위치를 유지한다.
- 실제 발견 일시 최신순으로 정렬한다. 로딩에서 최신 조건의 응답을 적용하고, 빈 결과는 검색 삭제·전체를 통해 개별 조건을 해제할 수 있게 한다. 오류에는 같은 조건 재시도를 제공하고 이전 결과가 있으면 유지한다. [승인 흐름](../03-structure/flows.mmd) · [상태와 복구 기준](../03-structure/states.csv) · [승인 문구](../05-design-system/copy.json)

### 레이아웃, 접근성 및 자산

- 390×844에서 목록 `y=248–690`은 세로 스크롤 영역이다. ‘지도 보기’와 하단 네 탭은 이 영역 밖에 고정한다. 실제 기기의 안전 영역 인셋과 글자 배율을 적용하고 목록 높이를 재계산한다. 좁은 화면에서는 거리 칩을 가로로 스크롤할 수 있게 하며, 카드 문구는 줄바꿈과 높이 확장으로 보존한다.
- 주요 조작 영역을 최소 44×44px로 유지한다. 화면 읽기에서는 기록의 곤충명, 관찰·채집 유형, 공개 지역, 발견 일시와 제공 가능한 거리를 하나의 상세 진입 조작으로 전달한다. 거리 칩과 탭에는 선택 상태를 제공한다. [토큰 및 치수](../05-design-system/tokens.json) · [컴포넌트](../05-design-system/components.json) · [아이콘](../05-design-system/icons.csv)
- 동등한 화면에서 지도 SDK의 공식 Mapbox 로고와 출처 버튼을 가리지 않도록 확인한다. 프로젝트 Lucide 아이콘을 사용한다. 전달한 곤충 사진은 시연·테스트 데이터에 사용한다. 사진의 출처·변경 표기 및 재배포 조건은 [인계 자산 안내](assets/README.md)를 따른다.
- 390×844 대표 화면 두 장, 플레이어 8단계 확인(초기 화면과 조작 7회), 기존 지도와 Mapbox 로고 보존을 확인했다. Figma 자동 검사 205개 노드에 이슈 0건, Chromium 웹 시안은 두 상태 모두 승인 캡처와 변경 픽셀 0개였다. [최종 검수 보고서](../07-validation/report.md) · [수용 기준 대조표](../07-validation/coverage.csv) · [실제 플레이어 기록](../07-validation/prototype-runtime.json)
