# 결정 기록

| 상태 | 결정 | 근거 |
| --- | --- | --- |
| 사용자 요청 | 메인 지도 패널을 위로 드래그해 ‘내 주변 발견’에 진입한다. 패널의 주요 콘텐츠 순서는 검색창, 거리 선택, 채집·발견 기록이다. | 사용자 요청과 [첨부 Kyro 참고 화면](../01-prd/evidence/kyroScrollMenu.png). |
| 기존 기준 | BugMap의 지도 탭과 다크 스타일을 이어받고 ‘지도 보기’로 같은 메인 지도에 복귀한다. 지도와 목록은 현재 위치 및 반경 조건을 공유한다. | [메인 지도 인계](../../bugmap-main-map-harness/08-handoff/HANDOFF.md) · [화면 명세](../../../docs/screens/main-map.md) · 제품 MAP-10. |
| 작업 제안 | 거리 버튼은 `전체`, `1 km 이내`, `3 km 이내`, `5 km 이내`로 한 번에 하나를 선택한다. 필터가 없는 첫 진입은 ‘전체’다. | 닫힌 패널에서 넘어온 뒤에도 현재 적용한 조건을 확인할 수 있는 누적 반경 구성이며, 숫자와 너비는 와이어프레임에서 확인한다. |
| 작업 제안 | 카드에 곤충 사진, 곤충명, 관찰·채집 유형, 공개 지역, 발견 일시를 표시한다. 현재 위치가 있을 때 공개 위치까지의 직선거리를 보조 정보로 표시한다. | 기존 MAP-01·02·05·07·10에 필요한 목록 정보. 시안의 사진과 값은 예시다. |
| 작업 제안 | 390×844 확장 화면은 전체 상태와 대표 ‘3 km 이내’ 상태로 확인한다. 기존 지도에서 진입, 대표 거리 전환, 지도 복귀를 Figma 프로토타입으로 연결한다. | 선택 여부와 결과 변화를 한 번 검토할 수 있는 최소 범위. Figma에서 지도 반경 오버레이를 위한 추가 지도 프레임은 만들지 않는다. |
