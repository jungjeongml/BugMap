발견 날짜·위치·기록 ID는 화면 검토용 예시다. 기록 7의 일곱 관찰 기록에는 서로 다른 사진을 사용했다. 미동정 상태를 시연하는 행에는 이름 모름을 표시한다. 배추흰나비·노랑나비·호랑나비의 원본은 Wikimedia Commons에서 받아 중앙 정사각형으로 자르고 264 × 264px PNG로 변환했다. 이전 하네스에서 가져온 사진에는 기존 크롭을 재사용했다. 사진 원본, 라이선스, 수정 내용, 파일·기록 ID 매핑은 [사진 목록](photo-sources.json)에 있다. CC BY-SA 사진의 자른 버전도 해당 원본과 같은 라이선스로 제공한다.
