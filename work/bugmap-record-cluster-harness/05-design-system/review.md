## 재현

저장소 루트에서 실행한다. 캡처에는 로컬 Chrome 또는 Chromium이 사용된다.

```sh
node work/bugmap-record-cluster-harness/05-design-system/build.mjs
node tools/design-harness/bin/design-harness design-md --project bugmap-record-cluster-harness --force
node work/bugmap-record-cluster-harness/05-design-system/capture.mjs
```

SVG와 PNG는 디자인 시스템의 정적 증거다. Figma 진입·닫기와 스크롤, 정확히 네 건일 때 시작·끝과 마지막 행의 기록 ID 수신, 큰 글자나 작은 화면에서의 적응은 후속 프로토타입과 검증 단계에 남아 있다. Figma에서 Pretendard를 적용할 수 있는지도 해당 단계에서 확인한다.
