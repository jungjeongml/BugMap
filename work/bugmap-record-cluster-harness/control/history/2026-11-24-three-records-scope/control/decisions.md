# 기록 묶음 선택 상태의 결정

## 확정

- `기록 3`은 지도에서 가까운 공개 기록 3건을 묶어 표시한 마커다. 패널의 ‘이 주변’은 그 마커에 속한 기록을 가리킨다.
- 패널은 하단 메뉴바 자리에 열린다. 지도와 선택 마커를 위에 표시하고, 패널에 `이 주변 관찰 기록 3건`, 사진 썸네일, 곤충 이름, 실제 발견 날짜를 표시한다.
- 다른 묶음을 누르면 선택과 내용이 함께 바뀐다. 닫으면 현재 지도 위치에서 메뉴바가 돌아온다. 각 기록 행은 해당 기록 상세로 이어진다.
- 제작 대상은 BugMapHarness Page 1의 기존 메인 지도에 붙는 선택 상태다. 시연에 쓰는 곤충·사진·날짜는 예시다. [제품 PRD](../../../docs/PRD.md#5-기능-요구사항) · [화면 명세](../../../docs/screens/main-map.md#기록-묶음-선택)

## 설계에서 정할 항목

- 한 화면에서 세 행을 읽을 수 있도록 패널의 높이, 행 간격, 썸네일 크기와 선택 마커의 시각적 강조를 와이어프레임에서 검토한다.
- 선택 상태에서 GPS·기록 작성 버튼과 검색 영역을 어떻게 배치할지 지도 가시성과 기존 진입 흐름을 고려해 검토한다. Mapbox 로고와 출처 버튼의 노출 및 조작은 수용 기준에 포함한다.
- 시연 기록의 사용 자산, 목록의 표시 순서, 안전 영역·긴 이름의 대응은 후속 단계에서 확인한다.
- Cursor 연결에서 제공하는 프로토타입 편집 기능과 기존 출처 동작은 Figma 단계에서 다시 확인한다. 제한이 있으면 승인된 수용 기준을 유지하고 미검증 범위와 가능한 대안을 기록한다.
