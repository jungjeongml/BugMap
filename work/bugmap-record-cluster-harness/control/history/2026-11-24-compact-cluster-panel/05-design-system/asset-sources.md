2026-11-24에 각 작성자의 Wikimedia Commons 원본 페이지에서 표시한 라이선스를 확인했다. 시안 사진은 인근 발견 시안에서 264×264 PNG로 크롭·리사이즈한 바이트를 다시 사용한다. 원본 파일 URL·해시·크롭 정보는 [사진 기록](photo-sources.json)에 있다. 사진은 시연용이며 공개 좌표·발견일은 예시다. Charles J. Sharp 사진의 크롭본에는 CC BY-SA 3.0을 적용한다. 이 이미지를 포함한 결과를 공유할 때 저작자·제목·출처·라이선스·크롭 및 리사이즈 정보를 함께 제공한다.

- 메인 지도 시안의 다크 지도 벡터를 그대로 사용했다. 지형은 저장소의 서울숲 모식도다. [지도 벡터](assets/map-dark.svg)
- 기존 시안의 공식 Mapbox 로고 88×23 SVG를 바이트와 종횡비 그대로 사용했다. 제품 지도에는 SDK 로고와 출처 정보 컨트롤을 사용한다. [공식 로고 원본](https://raw.githubusercontent.com/mapbox/mapbox-gl-js/main/src/css/svg/mapboxgl-ctrl-logo.svg) · [Mapbox 출처 지침](https://docs.mapbox.com/help/dive-deeper/attribution/)
- Pretendard 1.3.9 Medium 500과 Bold 700을 메인 지도 시안에서 가져왔다. [공식 릴리스](https://github.com/orioncactus/pretendard/releases/tag/v1.3.9) · [OFL 1.1](assets/pretendard-OFL.txt)
- Lucide React Native 1.70.0의 공식 아이콘 도형을 사용했다. [아이콘 카탈로그](icons.csv) · [ISC](assets/lucide-ISC.txt)

사진의 로컬 치수·바이트·SHA-256과 지도·글꼴 등 나머지 파일의 해시는 [자산 목록](assets-manifest.json)에 기록했다.
