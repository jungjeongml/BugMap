# Cursor MCP 작업 명령

`prepare.mjs`는 하네스의 현재 승인과 승인 자산의 SHA-256을 검사하고 `plan.json`을 생성한다. 기존 개발 Cursor MCP Plugin의 등록 정보 및 파일 해시를 확인하고 원본 백업과 임시 명령 파일을 작업용 임시 폴더에 출력한다. 임시 출력에는 원래 플러그인 파일과 승인 사진의 바이트가 있으므로 저장소 산출물에 포함하지 않는다.

프로젝트 전용 임시 명령은 대상 파일명, 페이지, 승인 계획 해시와 원본 마커를 대조한다. `bridge.mjs`로 `status`, `baseline`, `build`, `export`를 호출한다. 7건 화면으로 들어가는 두 연결에 스크롤 초기화 옵션을 설정한다. 확인용 `read-only` 준비 모드는 조회와 내보내기 명령만 활성화한다. `build`는 중복 프레임과 기존 마커 클릭 연결을 검사한다. 실패하면 제작 중 생성한 레이어와 변수, 원본에 적용한 클릭 연결을 복구한다. 정상 실행 뒤 별도 `export`로 실제 노드와 PNG를 읽는다.

`evidence.mjs`는 기존 루트, 메인 지도 PNG, 새 노드, 마커 경로, 사진의 원본 비율과 전체 기록 순서 등 원격 응답을 대조해 단계 파일로 저장한다. `restore.mjs`는 임시 플러그인 파일을 원본 백업과 대조하고 복원 이후의 SHA-256을 기록한다. 원래 명령을 다시 사용하도록 데스크톱의 Hot reload plugin을 실행한다.
