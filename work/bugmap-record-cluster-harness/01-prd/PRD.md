# BugMap 기록 묶음 선택 화면

로그인 후 발견 지도를 보는 사용자는 기록 묶음 마커를 눌러 그 주변에서 무엇이 발견됐는지 확인할 수 있다. 지도에 선택 위치를 남기고, 하단에서 기록의 사진·이름·발견 날짜를 확인한다. 4건 이상이면 네 번째 행 상단의 짧은 일부를 보여 목록이 이어진다는 것을 알 수 있게 한다.

## 제작 범위

- [BugMapHarness Page 1](https://www.figma.com/design/Dan8qlRM20XPkk7Mtd5riw/BugMapHarness?node-id=0-1)에 한국어 모바일 선택 상태 두 장을 제작한다. 3건인 `main-map/cluster-selected`는 기존 `기록 3` 마커 `41:394`에서 진입한다. 4건 이상인 `main-map/cluster-selected-overflow`는 기존 `기록 7` 마커 `41:390`에서 시연한다. 두 마커는 메인 지도 `41:81`에 있으며 검수 기준은 390×844다.
- 선택한 묶음 마커를 강조하고, 지도와 마커가 계속 보이는 상태에서 하단 메뉴바 자리에 `이 주변 관찰 기록 {건수}건` 패널을 연다. 제목의 건수는 선택한 마커에 속한 공개 기록 수다.
- 패널에는 닫기와 기록별 사진 썸네일, 곤충 이름, 실제 발견 날짜를 표시한다. 기록이 세 건이면 첫 화면에 모두 표시한다. 이름이 확인되지 않았을 때는 제품의 기존 문구 `이름 모름`을 적용한다.
- 기록이 네 건 이상이면 목록의 시작 위치에서 세 행 전체와 네 번째 행의 짧은 상단만 보여준다. 네 번째 행의 이름과 날짜는 스크롤한 뒤에 보인다. 목록을 아래로 스크롤하면 네 번째 행 전체와 마지막 기록까지 볼 수 있다. 제목과 닫기는 패널에 고정한다.
- 행을 누르면 해당 기록 상세의 전체 사진과 메모로 이어진다. 공개 좌표가 같은 기록도 서로 다른 기록 ID를 가진 행으로 표시하고 각각의 상세에 대응시킨다. 기록 상세 화면 자체, 데이터 조회와 위치 산정은 이번 제작 범위 밖이다.
- 프로토타입에서는 기존 지도에서 두 선택 상태로 진입하고 닫아 같은 지도로 돌아오는 흐름과, 7건 목록의 스크롤을 확인한다. 다른 묶음으로 바꾸면 해당 마커를 강조하고 새 목록을 맨 위에서 보여준다. 이 전환은 명세에 기록한다.

## 화면과 동작의 수용 기준

- 사용자 여정은 발견 지도 → 묶음 선택 → 기록 확인 또는 목록 스크롤 → 상세 진입 또는 닫기다. 닫으면 보고 있던 지도 위치에서 메뉴바가 다시 표시된다.
- 패널 위에 선택 마커, 지도, Mapbox 로고와 출처 버튼이 보여야 한다. 닫기·기록 행·출처 버튼의 터치 영역은 각각 최소 44×44다. 제품에서 출처 버튼을 누르면 지도 출처를 열 수 있어야 한다. 기존 Figma 출처 인터랙션이 있으면 선택 화면에서 재사용해 조작을 확인한다. 기존 인터랙션이 없으면 이 시안에서는 터치 영역과 가려짐을 확인하고, 출처 열기는 앱 검증 항목으로 기록한다.
- 390×844와 기본 글자 크기에서 3건 상태는 세 기록 전체가 보인다. 7건 상태는 첫 세 행 전체와 네 번째 행 높이의 ¼ 이내에 해당하는 윗부분만 보이며, 목록을 스크롤해 서로 다른 일곱 행의 사진·이름·날짜를 모두 확인한다. 일곱 번째 행은 하단 안전 영역 위에서 전체가 보이고 눌릴 수 있어야 한다. 검증용 HTML에서 7건 시안과 같은 패널·행 치수에 정확히 4건을 넣어 첫 세 행 전체와 네 번째 행 높이의 ¼ 이내에 해당하는 상단만 보이는 시작 상태를 확인한다. 목록을 끝까지 스크롤해 하단 안전 영역 위에 드러난 네 번째 행 전체를 누르고, 검증용 HTML이 그 기록의 ID를 받았는지 확인한다. 시작과 끝의 캡처를 남긴다. 작은 화면과 큰 글자에서는 행이 늘어날 수 있고 모든 기록을 스크롤해 읽을 수 있어야 한다. 긴 이름의 잘림·겹침과 마커·패널의 가시성도 확인한다. 실제 프로토타입 검증과 캡처에 의한 시각 검증은 각각 기록한다. ## 참고 자료와 남은 설계 판단

사용자가 첨부한 Kyro 광교호수공원 화면에서 지도·선택 위치·하단 정보 패널이 동시에 보이는 구성을 참고한다. BugMap의 정보 순서는 기록 사진·이름·날짜를 중심으로 잡는다. 3건 상태의 확대 와이어프레임을 기준으로 4건 이상 상태의 패널 높이, 네 번째 행이 보이는 깊이, 시연 자산을 후속 설계에서 검토한다. 이 단계에서 추가로 확정해야 할 제품 범위는 없다.
