# BugMap 첫 로그인 화면 — PRD v1

작성: 2026-11-16. 상태: 사람 승인 대기. 실행: bugmap-login-kyro.

## 목적과 사용자
곤충 관찰·채집 기록을 남기고 다른 사람의 발견을 찾으려는 사용자가 앱을 처음 열었을 때, 지도 기반 곤충 기록·공유 가치를 이해하고 로그인 제공자를 선택할 수 있는 첫 화면을 디자인한다.

## 사용자 확정 범위
- 편집 가능한 로그인 기본 페이지 프레임을 정확히 1개 제작한다.
- 추가 상태·오류·로딩·성공·다른 크기 화면은 생성하지 않는다. 이는 이번 납품 범위이며 실제 앱의 상태 요구사항을 삭제하지 않는다.
- example/kyroFirstPage.png를 시각 참고로 사용한다. 요청한 kyroFistPage.png는 없으며 일치하는 실제 파일을 직접 열었다.
- 현재 Figma Page 1의 BugMap-logo-vector 노드 126:706을 복제해 사용한다. 원본 비율·색·벡터 형태를 보존하고 원본은 수정하지 않는다. 제품 로고 재사용에 대한 명시 지시이며 일반 UI 아이콘 추출은 허용하지 않는다.
- Figma 구성은 CLI → 로컬 Cursor Talk To Figma MCP → 채널 b6q2ot0a로 수행한다. 다른 쓰기 도구로 조용히 전환하지 않는다.

## 구성 제안 · PRD 승인 대상
- 대표 크기 390×844, 화면/상태 login/default, Figma 루트 1개.
- 상단: 녹색 BugMap 로고가 읽히는 밝은 여백/영역. 원본 1000×310으로 조회했으며 비율 100:31을 유지한다.
- 중심: 지도 기반 배경과 간결한 소개. 제안 문구는 “작은 발견이 모여, 살아 있는 지도가 돼요”, 설명은 “발견한 곤충을 기록하고 지도에서 함께 나눠요.”
- 하단: 기존 로그인 명세의 카카오·네이버·Apple 순서를 유지하는 제안. 공식 제공자 브랜드 자산을 사용한다. 버튼 높이 최소48px, 개별 조작 영역 최소44×44px.
- 이용약관·개인정보처리방침 안내 영역을 두며 실제 URL 연결은 범위 밖이다.
- Kyro의 전면 지도와 로고/문구/버튼 계층을 참고한다. 점령 면적·인원 수·영토 경쟁 문구·노란 브랜드 로고는 옮기지 않는다. Kyro 캡처 자체를 배경으로 잘라 쓰지 않는다.
- 공통 녹색·중립색·Pretendard 우선·과한 그림자 배제·Lucide UI 아이콘 기준을 따른다. 지도 배경은 이번 로그인에 한정한 시각 예외 제안이며 세부 명암·토큰은 시스템 단계에서 검증한다.

## 핵심 여정과 범위 밖
앱 진입 → 서비스 가치와 브랜드 인지 → 로그인 제공자 선택. 선택 이후 실제 인증·성공 목적지·취소/실패 흐름은 이번 정적 디자인 산출물 밖이며 별도 화면으로 그리지 않는다.

제품 코드·백엔드·인증·실제 지도 SDK·배포·플러그인 설치·추가 Figma 파일 생성·기존 화면/로고 수정·다중 크기 납품은 제외한다. 근거 없는 AI 식별·성능·사용자 수·가입 시간·보안 보장 문구도 사용하지 않는다.

## 수용·검증 기준
- login/default 편집 가능한 프레임 1개, 390×844. 기존 페이지 작업과 원본 로고 보존.
- 지도 중심 분위기와 로고/소개/버튼의 계층, 곤충 기록·지도 공유 문구를 확인할 수 있음.
- 로고의 원본 비율·색·벡터 보존을 원격 조회와 실제 PNG 캡처로 확인. 제공자 공식 자산과 일반 UI 아이콘 출처 구분.
- 390×844에서 문구·버튼·안내의 겹침/잘림 없음. 일반 텍스트 대비4.5:1, 큰 텍스트3:1 이상. 버튼 최소48px, 조작 영역 최소44×44px.
- 실제 Cursor CLI 호출 기록·채널·노드 ID·캡처·대응 HTML과 lint 결과를 남김. 도구 제한은 미검증 또는 blocked로 표시.
- 하네스 1·4·5·7·8 사람 직접 승인 및 7단계 사람 리뷰 적용. AI 비평은 사람 승인을 대체하지 않음.

## 근거·현재 관찰
원본 버전은 control/project.json의 sourceDocuments SHA-256을 따른다. 기존 bugmap-login 검사는 1~5 passed, 6 figma 미완료다. 다중 상태와 다른 이번 범위로 기존 승인을 옮기지 않는다.

CLI 읽기 조회로 채널 b6q2ot0a의 Page 1(0:1)과 로고126:706의 이름/치수를 확인하고 PNG를 직접 열었다. 증거: control/cursor-document.json, control/cursor-logo.json, control/logo.png. 현재 페이지의 134:1239 “05 · 첫 로그인 / 지도 배경” 등 모든 기존 노드를 보존한다.

## 리서치 가정과 미검증
- 녹색 로고의 대비는 밝은 영역으로 확보할 수 있다고 가정한다. 실제 배경과 크기에서 후속 검증한다.
- 현 Cursor MCP의 복제·그리기·내보내기가 최종 토큰/벡터 검증까지 충족하는지는 미검증이다. 부족하면 Figma 완료로 표시하지 않는다.
- Talk 응답은 fileKey가 없어 정식 키와의 일치는 기존 노드 대조에 의존한다. 후속 쓰기 전 다시 대조한다.
- 제공자는 기존 명세 유지 제안이며 실제 인증 제공자 채택을 확정하지 않는다.
