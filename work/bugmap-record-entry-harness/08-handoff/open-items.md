| 확인 항목 | 제품에서 확인할 기준 |
| --- | --- |
| 공개 위치 정밀도 | 대략 공개 좌표의 격자 크기를 결정한다. 작성자의 좌표 접근, 타인용 응답과 지도·목록·클러스터의 공개 좌표 사용을 확인한다. 로그에서 정확한 좌표가 노출되지 않는지와 게시 사진의 위치 EXIF 제거를 검증한다. |
| 위치와 사진 권한 | 카메라·파일 보관함과 GPS의 허용·거부·취소를 확인한다. GPS 실패 시 지도 직접 선택으로 이어지고 편집 중인 위치와 사진이 보존돼야 한다. |
| 사진 장수와 업로드 정책 | 0장·4장 이상은 저장을 거부하고, 1~3장은 다른 필수값이 유효하면 저장할 수 있게 한다. 3장에서 한 장을 삭제한 뒤 다시 추가할 수 있는지 확인한다. 파일 크기·형식·압축·보관 기준은 제품 결정에 따른다. |
| 부분 입력과 키보드 | 이름 또는 이름 모름, 기록 유형, 발견 날짜·시간을 빠뜨렸을 때 입력이 필요한 항목을 찾을 수 있는지 확인한다. 글자 배율·키보드·안전 영역이 바뀌어도 메모와 작성완료를 조작할 수 있게 한다. |
| 발견 일시와 메모 | 과거 발견 시각을 저장하고 게시 시각과 구분한다. 날짜·시간 선택기의 취소와 재편집, 상세 조회의 여러 줄 메모 보존을 확인한다. |
| 저장·초안·지도 복귀 | 연속 탭과 응답 유실·업로드 실패에서 중복 생성 없이 재시도한다. 미저장 이탈 후 계속 작성할 때 초안을 유지하고, 저장 성공 후 기존 지도에 새 기록이 반영되는지 확인한다. |
| 실기기 접근성 | 키보드 및 화면 읽기로 이동 순서, 선택·비활성 상태, 동작 이름, 오류와 저장 결과를 확인한다. 작은 화면과 확대 글꼴에서 주요 조작 영역 및 하단 고정을 확인한다. |
