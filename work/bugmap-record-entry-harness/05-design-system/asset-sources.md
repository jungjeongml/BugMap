# 작성 화면 자산 출처

예시의 왕사슴벌레 사진은 공개 자료에서 가져왔다. 시안에 표시된 위치·발견 시각은 시연 값이다. 각 사진은 독립적인 원출처를 가지며, 한 개체를 같은 장소와 시간에 촬영한 기록으로 사용하지 않는다. 세 썸네일을 크롭하고 342×270px PNG로 리사이즈했으며 EXIF와 텍스트 메타데이터를 제거했다. 원본과 썸네일 해시 및 좌표는 [사진 명세](photo-sources.json)에 있다.

사진이 포함된 시안이나 썸네일을 공유할 때 위 작가·제목·원본 출처와 라이선스 링크, 크롭·리사이즈 및 메타데이터 제거를 함께 표기한다. 세 사진의 썸네일에도 같은 라이선스를 적용한다. [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/)
