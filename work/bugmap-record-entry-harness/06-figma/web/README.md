# 기록 작성 HTML

- [첫 진입](record-entry--default.html)은 사진 0장과 작성완료 비활성을 표시한다.
- [입력 완료](record-entry--ready.html)는 사진 3장, 필수 입력 예시, 작성완료 활성 상태를 표시한다.
- 승인 시안의 Pretendard 서체, Lucide 벡터, 사진 원본, 색상과 문구를 사용한다. 390×844에서 제목과 작성완료는 고정되고 본문이 세로로 스크롤된다. 곤충 이름과 여러 줄 메모는 직접 입력해 볼 수 있다.
- 메모와 이름 편집은 열린 페이지의 입력 예시다. 카메라·사진 선택기·지도·GPS·날짜 및 시간 선택기·저장은 제품 흐름에 정의되어 있다.
- 사진 출처·CC BY-SA 3.0·편집 이력은 [승인 자산 출처](../../05-design-system/asset-sources.md)에 기록되어 있다. Pretendard와 Lucide 라이선스는 assets 폴더에 있다.
