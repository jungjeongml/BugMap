# 로컬 제작 도구

승인된 두 폼의 기하, 문구, Lucide 아이콘과 사진을 계산한 입력은 plan.json에 있다. 대상은 BugMapHarness Page 1이다.

- prepare.mjs는 승인 ID와 원본 SHA-256을 다시 대조해 계획을 만든다. 준비 단계에서 기존 플러그인 설치 경로를 읽는다. 어댑터를 만들려면 저장소 절대 경로를 전달하고 --adapter를 사용한다.
- plugin.js는 편집 가능한 화면 구성, 기존 지도 보존 대조, 원격 PNG와 네이티브 노드 조회를 수행한다. 제작 명령은 이미 만들어진 폼에 다시 실행하면 중단한다. 기존 지도 버튼, 로그인·지도·내 주변 발견 및 승인 계획이 정확히 일치할 때만 변경한다.
- draw.mjs는 현재 사용자 승인과 입력 해시를 확인한 뒤 status, baseline, build, export를 실행한다. 수정 작업에서 repair는 이번 제작으로 생성된 파일·프레임·벡터 ID와 정확한 가져오기 상태를 검사한다. receipt는 임시 로컬 원본 응답에서 산출물을 다시 만드는 경우에만 사용한다.
- mock-test.mjs는 연결 모의 환경의 대상 보호, 기존 반응 보존, 실패 복원, 중복 방지를 확인한다. 원격 증거는 별도 JSON과 PNG에 있다.
- prepare-web.mjs는 대응 HTML과 CSS, 폰트와 사진을 만든다. 화면 상태, 스크롤, 예시 입력은 web/에서 확인한다.
- 실행 중 Cursor 명령 라우터의 준비 코드와 임시 채널은 저장소 밖 임시 경로에만 유지했다. 실제 기존 설치를 사용한 뒤 두 원본 파일을 SHA-256으로 복구 확인했다. [초기 제작 후](../cursor-source-restore.json) · [벡터 보정 후](../cursor-second-restore.json)
