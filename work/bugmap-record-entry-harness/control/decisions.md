# 결정 기록

| 상태 | 결정 | 근거 |
| --- | --- | --- |
| 사용자 요청 | 메인의 기록하기에서 작성 화면을 열고 촬영 또는 첨부, 발견 위치, 발견 날짜·시간, 여러 줄 메모와 최하단 작성완료를 제공한다. | 현재 요청. |
| 기존 제품 기준 | 사진 1~3장, 곤충 이름 또는 이름 모름, 관찰·채집, 발견 위치와 실제 발견 일시를 입력한다. 메모는 선택이다. | [제품 PRD](../../../docs/PRD.md) · [작성 화면 명세](../../../docs/screens/record-entry.md). |
| 사용자 확정 | 촬영·첨부를 합산해 최소 1장과 최대 3장을 적용한다. 사진이 3장이면 추가를 비활성화하고 사진을 삭제하면 다시 추가할 수 있게 한다. | 2026-11-20 사용자 결정. [장수 비교](../01-prd/PRD.md#사진-장수-결정). |
| 승인 대기 제안 | 기존 다크 지도에서 같은 Page 1의 390×844 첫 진입·필수 입력 완료 화면을 열고 복귀한다. 작성 폼을 스크롤할 수 있게 하고 작성완료를 고정한다. | [메인 지도 인계](../../bugmap-main-map-harness/08-handoff/HANDOFF.md) · [다크 가이드](../../../docs/DESIGN.md#지도-중심-다크-팔레트). |
| 사용자 결정 | 작성 폼의 ‘위치 공개 범위’ 선택을 제거하고 발견 위치를 필수로 받는다. | 2026-11-20 사용자 요청. [작성 PRD](../01-prd/PRD.md). |
| 설계안 | 새 기록은 공개 위치를 자동으로 생성해 다른 사용자의 지도와 조회에 대략적인 위치를 표시한다. | [제품 PRD](../../../docs/PRD.md) · [TDD](../../../docs/TDD.md). |
| 후속 제품 결정 | 사진의 최대 바이트·형식·압축·보관 기준과 대략적인 공개 위치 해상도를 확인한다. | [제품 PRD](../../../docs/PRD.md) · [TDD](../../../docs/TDD.md). |
