# BugMapHarness 발견·채집 기록 작성

로그인한 사용자가 메인 지도에서 발견하거나 채집한 곤충을 사진·위치·일시와 함께 기록한다. 현장에서 한 장을 촬영해 빠르게 기록하거나 나중에 보관한 사진을 첨부해 발견 정보를 입력할 수 있게 한다.

## 화면과 동작

- [BugMapHarness 메인 지도](https://www.figma.com/design/Dan8qlRM20XPkk7Mtd5riw/BugMapHarness?node-id=41-81)의 ‘발견/채집 기록하기’ 버튼 `41:443`에서 별도 작성 화면으로 진입한다. 뒤로 가면 기존 지도를 연다. 미저장 입력이 있는 경우 이탈 확인 경로를 제공한다.
- 상단에 ‘발견·채집 기록’ 제목과 뒤로 가기를 둔다. 스크롤 폼은 **사진 → 곤충 이름과 관찰·채집 유형 → 발견 위치 → 발견 날짜·시간 → 메모** 순서다. 최하단에 ‘작성완료’를 고정하고 기기의 안전 영역을 적용한다. 본문에서 필드에 집중할 수 있도록 기존 지도 탭은 작성 화면에서 숨기는 안으로 검토한다.
- 사진에는 ‘촬영하기’와 ‘사진 첨부’를 제공한다. 촬영과 첨부 장수를 합산하고 개별 썸네일에서 삭제할 수 있게 한다. 사진은 최소 1장, 최대 3장으로 확정했다. 카운터는 ‘0/3장’ 형식으로 표시한다. 3장이면 추가 동작을 비활성화하고 한 장을 삭제하면 다시 추가할 수 있게 한다. 여러 장을 고를 때는 남은 장수를 안내한다. 업로드·저장 실패 후에는 입력을 유지하고 재시도할 수 있게 한다.
- 기존 요건에 따라 곤충 이름 또는 ‘이름 모름’과 ‘관찰’·‘채집’ 유형을 입력한다. 메모는 선택이다. 주변 환경이나 곤충 행동을 적을 수 있는 여러 줄 입력창을 제공한다.
- 필수 위치 입력은 ‘발견 위치’ 한 항목으로 구성한다. ‘현재 위치 사용’을 제공하고 위치 권한이 없거나 위치를 받아올 수 없을 때도 지도에서 직접 확인·수정할 수 있게 한다. 새 기록은 발견 위치를 바탕으로 대략적인 공개 위치를 자동 생성하는 안이다. 다른 사용자의 지도와 조회에는 공개 좌표만 제공한다. 사진을 게시하기 전에 EXIF 위치 정보를 제거하고, 공개 위치 해상도는 후속 제품 결정으로 둔다.
- 발견 날짜와 시간을 각각 선택하고 수정할 수 있어야 한다. 이전에 발견한 기록도 등록할 수 있으며 발견 일시와 게시 시각을 별도로 다룬다.
- ‘작성완료’는 사진 1~3장, 이름 또는 ‘이름 모름’, 유형, 발견 위치, 발견 일시가 유효할 때 활성화한다. 저장 중 중복 제출을 막고 성공 시 같은 메인 지도에 새 기록을 반영하는 제품 흐름을 정의한다.

## 사진 장수 결정

| 상한 | 판단 |
| --- | --- |
| **3장 채택** | 전체 모습, 구별되는 특징, 주변 환경을 각 한 장에 담을 수 있고 간단한 기록은 1장부터 등록할 수 있다. |
| 4장 | 다른 각도에서 찍은 사진을 한 장 더 담을 여유가 있다. |
| 5장 | 다른 측면이나 추가 특징을 담을 여유가 있다. 상한까지 채운 기록은 업로드 데이터와 사진을 관리할 영역도 늘어난다. |

iNaturalist의 여러 각도와 발견 환경 촬영 안내를 참고했다. 사용자가 최대 3장을 선택했다. 사진의 최대 바이트·압축·보관 정책은 제품 결정으로 둔다. [iNaturalist 곤충 촬영 가이드](https://www.inaturalist.org/pages/insects) · [BugMap 제품 PRD](../../../docs/PRD.md)

## 대표 시안과 범위

- **첫 진입**과 **사진 3장 및 필수 입력 완료**를 각각 390×844 다크 화면으로 제작하는 안이다. 촬영·첨부와 ‘0/3장’, 입력 완료의 썸네일·‘3/3장’ 및 상한 안내, ‘작성완료’ 활성·비활성을 대조한다. Figma 플레이어에서 폼을 직접 스크롤해 하단 위치·일시·메모에 접근할 수 있고 ‘작성완료’가 고정되는지 확인한다.
- 기존 지도 버튼에서 첫 화면으로 진입하고 뒤로 가면 같은 지도에 복귀하는 Figma 프로토타입을 목표로 한다. 촬영·첨부, 권한 거부와 다른 사진 입력 경로, 1장으로 저장 가능한 조건, 삭제 후 재추가, 필수 입력과 위치 직접 선택, 실패 복구, 저장 및 이탈 확인은 흐름과 상태표에서 다룬다. 실제 카메라·파일 접근·GPS·서비스 저장과 별도 선택기 화면은 제품 구현과 후속 설계 범위다.
- 같은 BugMapHarness Page 1의 기존 메인 지도·내 주변 발견·로그인 화면을 보존한다. 작성 화면으로 가는 연결을 기존 기록 버튼에 추가한다. [메인 지도 인계](../../bugmap-main-map-harness/08-handoff/HANDOFF.md) · [작성 화면 명세](../../../docs/screens/record-entry.md) · [BugMap 다크 가이드](../../../docs/DESIGN.md#지도-중심-다크-팔레트)

## 수용 기준

[요구사항표](requirements.csv)의 진입·복귀, 사진, 입력 순서, 완료 상태와 조작 영역을 화면·흐름·Figma 노드로 대조한다. 이미 승인한 지도 동작과 공식 Mapbox 로고는 지도 프레임 제작 전후를 비교해 확인한다.
