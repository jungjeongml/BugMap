# 닉네임 설정 구현 계획

기준은 [승인 디자인 인계](../../../work/bugmap-nickname-harness/08-handoff/HANDOFF.md)와 가입 시 필수 설정, 영문 대소문자 무시 중복 정책이다.

1. 인증 서버 테스트로 가입 직후 미설정, 유효성 검사, 동시 중복, 재시도, 세션 복구와 웹 출처 검사를 확인한다.
2. SQLite 가입·세션 경로에 nullable 프로필을 연결한다. 시작 시 기존 스키마를 갱신하고 유니크 인덱스를 적용한다. 모바일 Bearer와 웹 쿠키에서 본인의 첫 닉네임만 저장한다.
3. 웹·모바일 인증 클라이언트와 닉네임 화면을 연결한다. 저장 성공을 확인한 뒤 지도에 진입하고 실패 시 입력을 유지한다.
4. 서버 테스트, 프론트 테스트, 타입 검사와 웹 빌드를 실행한다. 검증 결과와 남은 실기기 확인을 기록한다.
